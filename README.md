# 바이블로그

성경의 장면 속을 직접 걸어 다니는 웹 3D RPG다. 바이블(Bible)과 블로그(Blog)를 합친 이름으로, 내가 본 성경의 순간을 하나씩 기록해 나간다는 뜻을 담았다.

플레이어는 환상 속에 불려 간 오늘의 사람이다. 대천사와 함께 사건 현장을 지켜보고 둘러보지만, 성경의 사건을 바꾸지는 않는다. 전투 없이 탐험, 대화, 퀘스트, 구절 퀴즈로 진행한다.

## 지금 플레이할 수 있는 장

1. 천국(프롤로그): 이름과 모습을 정하고 대천사를 만난다.
2. 창조(창 1:1~2:3): 첫째 날부터 일곱째 날까지 세상이 지어지는 모습을 지켜본다.
3. 에덴(창 2:4~3:24): 아담과 하와, 네 강, 동물의 이름, 타락과 추방을 따라간 뒤 구절 퀴즈로 마무리한다.
4. 창세기 월드의 나머지(1-3 가인과 아벨부터 1-13 요셉과 형제들, 곁길 에녹·하갈): 쉼터의 빛의 문에서 월드 지도를 열어 고른다.

성경 본문은 쉬운 말로 각색했고, 대사마다 장절을 붙였다. 본문에 없는 연출은 각색임을 밝힌다.

## 실행

```bash
npm install
npm run dev     # http://localhost:5173
```

PC는 WASD와 클릭, 휴대폰은 탭과 밀기로 움직인다. Three.js와 Vite로 만들었다.
