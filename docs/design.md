# 바이블로그 설계

설계 인터뷰(2026-10-31, 2026-11-01)와 이후 요청으로 확정한 결정을 기록한다. 결정을 바꾸면 이 파일을 먼저 고친다.

## 게임

- 제목: **바이블로그**. 바이블과 블로그를 겹쳐 읽는다. 내가 본 성경의 순간을 기록해 나간다는 뜻이다.
- 범위: 이야기와 시스템 모두 성경 전반을 다룬다. 최종 목표는 정경 순서 전체다.
- 장르: 스토리 감상형이 아니라, 관찰자가 성경 안을 걸으며 자라는 성장형 RPG다(2026-11-01 결정).

## 만든 장

1. 천국(프롤로그): 오늘을 사는 플레이어가 환상 속에서 천국에 불려 간다(계 4:1의 요한처럼). 이름과 천국에서의 모습을 정하고, 빛기둥에서 내려온 대천사를 만나 빛의 문으로 걸어간다.
2. 창조(창 1:1~2:3): 관찰자는 하루씩 지켜보고 둘러본다. 넷째 날에는 해·달·별이 하늘을 돌며 뜨고 진다.
3. 에덴(창 2:4~3:24): 지상에서의 모습을 정한 뒤 아담이 지음 받는 장면, 네 강 찾기, 동물 이름 짓기(도감 카드), 하와, 열매를 따서 바구니에 담기를 거쳐 타락과 추방, 구절 퀴즈로 끝난다.

## 확정한 결정

### 이야기와 표현

| 항목 | 결정 |
|---|---|
| 플레이어 | 관찰자. 성경 사건은 바꿀 수 없지만 현장에 참여한다 |
| 관찰자 설정 | 환상 속에 불려 간 오늘의 사람 (영혼 선재설로 읽히지 않게) |
| 관찰자 모습 | 천국: 반투명하게 빛나는 형체. 지상: 사람 모습(피부·머리·옷·소품)에 은은한 빛과 발밑 빛 고리 |
| 지상 꾸미기 | 처음 땅에 내려가기 전, 전용 꾸미기 화면(캐릭터가 주인공, 탭 패널)에서 고른다 |
| 지상에서의 존재 | 사건이 진행되는 동안에는 사람들에게 보이지 않는다. 대천사가 동행한다 |
| 인물과의 대화 | 사건 사이의 빈 시간(막간)에만 인물이 관찰자를 알아보고 대화한다. 대화는 사건의 흐름을 바꾸지 않는다(질문하기, 일 돕기, 마음 듣기) |
| 하나님 | 빛기둥, 움직이는 빛, 음성(대사 창)으로만 표현한다. 형상은 없다 |
| 아담과 하와 | 처음부터 잎사귀와 긴 머리로 가린다. 타락 뒤 무화과 잎, 추방 때 가죽옷 |
| 타락 연출 | 동산의 색과 조명이 흐리고 차갑게 바뀐다. 뱀은 교활하지만 무섭지 않게 |
| 여섯째 날의 사람 | 창 1:27 서술로만 다룬다. 사람을 짓는 장면은 창 2장(에덴)에서 보여 준다 |
| 하나님의 이름표 | 본문의 이름을 따른다. 창 1:1~2:3은 엘로힘, 프롤로그와 창 2:4부터는 YHWH |
| 대상 | 교회 신자 전 연령 |
| 표현 | 성경을 그대로 전한다. 본문의 사건과 결과(전투 포함)는 보여 주되, 피나 상처는 자세히 그리지 않는다 |
| 성경 본문 | 쉬운 말로 각색하고 장절을 표기한다. 개역개정 원문은 싣지 않는다 |
| 감수 | 세 층으로 나눈다. ① 자동 점검(`npm run check`) ② 각색 목록 검수: `npm run review`가 스테이지마다 본문에 없는 것(장절 없는 대사, 막간·깊은 대화, 성경 근거 주석)을 `docs/review/`에 마크다운으로 뽑고 사용자가 확인한다(원하면 체크리스트 페이지로도 연다) ③ 스테이지 하나를 끝까지 플레이해 걸리는 것만 짚는다 |

### 게임 구조

| 항목 | 결정 |
|---|---|
| 핵심 플레이 | 탐험, 막간 대화, 퀘스트, 사건별 도전(전투 포함), 구절 퀴즈 |
| 구조 | 월드(성경의 책 하나) → 스테이지(사건 하나). 예: 1-1 창조, 1-2 에덴. 정경 순서로 만든다 |
| 스테이지 틀 | 모든 스테이지가 같은 틀: 연출 장면, 퀘스트나 도전 1~2개, 막간 1개, 핵심 말씀 1개(끝 퀴즈), 도감 항목 몇 개. 족보는 연결 장면이나 도감 기록으로 처리한다 |
| 스테이지 열림 | 앞 스테이지를 마치면 다음이 열린다(레벨 조건 없음) |
| 장면 연결 | 스테이지 안의 장면은 끊김 없이 이어진다 |
| 저장 | 지점마다 자동 저장. 열린 지점은 '처음부터'를 눌러도 남는다 |
| 이어하기 | 장 카드(진행도 표시) → 장 안의 지점 목록. 못 간 장은 잠긴 카드 |
| 기기 | PC(WASD, 클릭, Space)와 휴대폰(탭, 밀기) |

### 성장 시스템 (2026-11-01 인터뷰)

| 항목 | 결정 |
|---|---|
| 성장하는 대상 | 관찰자 자신. 성경 인물은 관계와 도감 기록으로 쌓인다 |
| 성령의 열매 | 갈 5:22~23의 아홉 가지를 능력치로 쓴다. 화면 이름은 쉬운 말(사랑, 기쁨, 화평, 인내, 친절, 선함, 신실, 온유, 절제), 설명 칸에서 개역개정 단어(희락, 오래 참음, 자비, 양선, 충성)를 한 번 함께 보여 준다. 화면에서는 줄여서 '열매'라고 쓰지 않는다(진짜 열매와 헷갈림) |
| 열매가 자라는 법 | 퀘스트를 마치면 정해진 열매가 자라고(기본), 막간 선택이 어느 열매를 더 키울지 정한다(개성). 선택지는 모두 좋은 행동이고 자라는 열매만 다르다. 열매는 줄어들지 않는다 |
| 상태 창 | 아홉 가지 열매를 레이더 차트로 보여 주고, 가장 큰 열매를 기준으로 닮은 성경 인물을 긍정형 문장으로 보여 준다. 후보는 도감에서 만난 인물이다. 인물별 열매 모양은 각색 목록 검수에 올린다 |
| 레벨 | 모든 행동에서 쌓이는 경험치로 오른다. 오를 때마다 칭호(성경 표현), 꾸미기, 인벤토리 칸이 열린다 |
| 달란트 | 경험치와 별개의 화폐. 관찰자만 쓰는 하늘의 달란트(마 25:14~30). 쉼터 상점에서 도구와 꾸미기를 산다 |
| 인벤토리 | 도구 탭과 꾸미기 탭. 도구는 쓰임이 있는 물건이고(예: 물매, 양각 나팔, 등잔, 물동이) 몸에 지니면 모양도 바뀐다. 쓸 곳에서 다 쓰면 자동으로 사라진다 |
| 기념물 | 스테이지마다 받는 물건(예: 무화과 잎, 올리브 잎). 인벤토리에 두지 않고 도감에만 남는다 |
| 도감 | 인물, 피조물(사람을 뺀 지음 받은 것: 동물·새·물고기·나무·식물), 장소, 물건, 말씀. 항목마다 처음 만난 스테이지를 표시한다. 말씀은 스테이지마다 핵심 구절 1~2개만 담는다 |
| 인물과의 관계 | 만남 → 대화 → 동행(그 인물의 일을 함께 함) 세 단계. 숫자(친밀도)는 쓰지 않는다. 여러 스테이지에 나오는 인물은 단계가 이어진다. 동행에 이르면 그 인물과 관련된 열매가 자란다 |
| 깊은 대화 | 관계 단계(대화 이상)와 레벨이 함께 일정 이상일 때 막간에서 열린다. 각색 목록 검수에 따로 표시한다 |
| 전투·도전 | 틀은 사건별 도전(본문이 정한 승리 방법을 따른다. 예: 여리고 행진과 나팔, 다윗의 물매, 기드온의 신호), 조작은 쿼터뷰 실시간 액션. 성령의 열매가 도전을 돕고(예: 절제가 높으면 물매 손떨림이 줄어듦), 도구는 그 사건에서 쓰인다 |
| 메뉴 | 상태 창·인벤토리·도감은 걷는 중에 메뉴로 연다(연출 중에는 막는다). 상점과 스테이지 선택은 쉼터에서만 한다 |
| 쉼터 | 천국 장면을 넓힌 거점. 스테이지를 마치면 돌아오고, 빛의 문이 월드 지도로 가는 입구다 |

### 만드는 순서

1. 에덴(1-2)에 성장 시스템을 넣는다: 성령의 열매, 레벨, 달란트, 인벤토리, 도감 다섯 분류, 막간 1개, 상태 창.
2. 월드·스테이지 구조와 쉼터를 만든다(지금의 장 목록 `src/data/chapters.js`와 열린 지점을 넓힌다).
3. 창세기 월드를 정경 순서로 완성한다. 스테이지 목록 초안은 이때 함께 정한다.
4. 같은 틀로 다음 월드(출애굽기…)를 만든다.

### 레퍼런스에서 가져온 규칙 (2026-11-01 확정)

조사 근거와 출처는 [`research/rpg-references.md`](research/rpg-references.md)에 있다. 수치(★)는 1단계 구현 뒤 체험하고 조정한다.

| 영역 | 규칙 | 근거 |
|---|---|---|
| 열매 표시 | 열매마다 5단계(씨앗·새싹·줄기·꽃·결실), 점수는 숨김 | 페르소나 5R |
| 열매 수치★ | 단계 경계 0·10·25·45·70점. 퀘스트 +4, 막간 선택 +2, 동행 도달 +3 | 제안 |
| 열매가 여는 것 | 기본 선택지 셋은 늘 열림. 특정 열매 단계에서 선택지 하나 추가 | 페르소나 4 |
| 관계 오름 | 만남은 자동, 대화·동행은 행동 한 번. 숫자·감소·선물 없음 | 스타듀(반대 사례) |
| 막간 분량★ | 끝까지 하는 대화는 막간마다 한 명(5~8번 주고받기, 약 2분), 나머지는 짧은 인사 | 제안 |
| 도전 조작 | 모든 도전이 이동·행동·도구 3가지로 같다. 사건마다 행동 버튼의 뜻만 바뀐다. 성공이 가까우면 금빛 신호 | 언더테일 |
| 도구 획득 | 도전에 쓸 도구는 같은 스테이지 앞부분에서 얻는다 | 젤다 |
| 도전 보조★ | 열매 단계당 보조 8%, 최대 32%. 실패해도 감점 없이 다시 하고 결말은 본문 그대로 | 제안 |
| 도감 칸 | 미발견(번호·물음표), 놓침(실루엣·스테이지 힌트), 만남(전체). 설명은 본문 사실·장절 한 줄 + 관찰자 메모 한 줄. 완성 보상은 칭호·꾸미기만 | 포켓몬 |
| 지도 표시 | 볼거리가 남은 스테이지에 작은 별. 곁길 스테이지는 월드당 0~2개. 대표 진행도는 "말씀 n/전체" | 마리오 월드 |

## 나중에 정할 항목

- 시대별 지상 모습(옷)을 스테이지마다 다시 고르게 할지
- 스테이지 하나의 플레이 시간과 경험치·달란트 수치
- 막간 대화 화면과 선택지 형식
- 쉼터와 월드 지도의 모양
- 3D 모델의 크기와 폴리곤 수 기준
- 교인들이 함께 모이는 마을(채팅): 창세기 월드가 완성된 뒤 다시 꺼낸다. 서버·로그인·대화 관리가 필요한 별도 과제다. 쉼터가 그 자리가 될 수 있다
