# 바이블로그 설계

설계 인터뷰(2026-10-31)와 이후 요청으로 확정한 결정을 기록한다. 결정을 바꾸면 이 파일을 먼저 고친다.

## 게임

- 제목: **바이블로그**. 바이블과 블로그를 겹쳐 읽는다. 내가 본 성경의 순간을 기록해 나간다는 뜻이다.
- 범위: 성경 전반을 장 단위로 이어 간다. 장 목록은 `src/data/chapters.js` 한 곳에서 관리한다.

## 만든 장

1. 천국(프롤로그): 오늘을 사는 플레이어가 환상 속에서 천국에 불려 간다(계 4:1의 요한처럼). 이름과 천국에서의 모습을 정하고, 빛기둥에서 내려온 대천사를 만나 빛의 문으로 걸어간다.
2. 창조(창 1:1~2:3): 관찰자는 하루씩 지켜보고 둘러본다. 넷째 날에는 해·달·별이 하늘을 돌며 뜨고 진다.
3. 에덴(창 2:4~3:24): 지상에서의 모습을 정한 뒤 아담이 지음 받는 장면, 네 강 찾기, 동물 기록, 하와, 열매 모으기를 거쳐 타락과 추방, 구절 퀴즈로 끝난다.

## 확정한 결정

### 이야기와 표현

| 항목 | 결정 |
|---|---|
| 플레이어 | 관찰자. 성경 사건은 바꿀 수 없지만 현장에 참여한다 |
| 관찰자 설정 | 환상 속에 불려 간 오늘의 사람 (영혼 선재설로 읽히지 않게) |
| 관찰자 모습 | 천국: 반투명하게 빛나는 형체. 지상: 사람 모습(피부·머리·옷·소품)에 은은한 빛과 발밑 빛 고리 |
| 지상 꾸미기 | 처음 땅에 내려가기 전, 전용 꾸미기 화면(캐릭터가 주인공, 탭 패널)에서 고른다 |
| 지상에서의 존재 | 사람들에게 보이지 않는다. 대천사가 동행한다 |
| 하나님 | 빛기둥, 움직이는 빛, 음성(대사 창)으로만 표현한다. 형상은 없다 |
| 아담과 하와 | 처음부터 잎사귀와 긴 머리로 가린다. 타락 뒤 무화과 잎, 추방 때 가죽옷 |
| 타락 연출 | 동산의 색과 조명이 흐리고 차갑게 바뀐다. 뱀은 교활하지만 무섭지 않게 |
| 여섯째 날의 사람 | 창 1:27 서술로만 다룬다. 사람을 짓는 장면은 창 2장(에덴)에서 보여 준다 |
| 하나님의 이름표 | 본문의 이름을 따른다. 창 1:1~2:3은 엘로힘, 프롤로그와 창 2:4부터는 YHWH |
| 대상 | 교회 신자 전 연령. 폭력은 암시로 처리한다 |
| 성경 본문 | 쉬운 말로 각색하고 장절을 표기한다. 개역개정 원문은 싣지 않는다 |
| 감수 | 사용자가 직접 본문과 대조해 확인한다 |

### 게임 구조

| 항목 | 결정 |
|---|---|
| 핵심 플레이 | 탐험, 대화, 퀘스트(찾기·기록·모으기), 구절 퀴즈. 전투는 없다 |
| 장 연결 | 장면이 끊김 없이 이어진다 |
| 저장 | 지점마다 자동 저장. 열린 지점은 '처음부터'를 눌러도 남는다 |
| 이어하기 | 장 카드(진행도 표시) → 장 안의 지점 목록. 못 간 장은 잠긴 카드 |
| 기기 | PC(WASD, 클릭, Space)와 휴대폰(탭, 밀기) |

### 기술과 에셋

| 항목 | 결정 |
|---|---|
| 기술 | Three.js + Vite, 정적 파일 |
| 화면 | 로우폴리 + 픽셀화 후처리(RenderPixelatedPass), 쿼터뷰 |
| 3D 모델 | 직접 모델링(.glb). 그 전까지 코드로 만든 임시 도형을 쓴다 |
| 소리 | 저작권이 끝난 찬송가 선율을 코드로 8비트 편곡해 연주한다(아직 없음) |
| 배포 | 무료 공개 웹 (GitHub Pages나 Cloudflare Pages) |

## 만드는 규칙

디자인 시스템(3D 부품, 화면 토큰), 대사 규칙, 퀘스트·연출 기준, 작업 방식은 [`standards/`](standards/README.md)에 주제별로 둔다.

## 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 찬송가 선율 오류 | 곡별 미리듣기로 사용자가 확인한 곡만 넣는다 |
| 찬송가 저작권 | 작곡 연도와 사망 연도를 기록하고 원곡 선율만 쓴다 |
| 감수 누락 | 대사를 장절이 붙은 데이터로 분리해 대조한다 |
| 모델링 지연 | 임시 도형으로 먼저 완성하고 모델은 교체한다 |
| 저장 소실 | 브라우저에만 저장된다고 첫 화면에 안내한다 |

## 나중에 정할 항목

- 출애굽기 이후 시대에서 관찰자가 군중에게 보이는지 여부
- 시대별 지상 모습(옷)을 장마다 다시 고르게 할지
- 바이블로그 기록(동물, 구절 카드)을 모아 보는 화면
- 장 하나의 플레이 시간
- 3D 모델의 크기와 폴리곤 수 기준
