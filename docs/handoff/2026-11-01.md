# 핸드오프 2026-11-01: 에덴 다듬기와 UI 가독성

이전 세션에서 받은 요청 목록을 다음 세션이 그대로 이어서 처리하도록 정리한다. 규칙은 [`../standards/`](../standards/README.md), 게임 결정은 [`../design.md`](../design.md)에 있으니 여기에는 반복하지 않는다.

## 지금 상태

- 바이블로그(웹 3D 성경 RPG, Three.js + Vite). 천국 프롤로그 → 창조 7일 → 지상 꾸미기 화면 → 에덴(창 2~3장) → 구절 퀴즈까지 끝까지 플레이된다.
- 실행: `npm run dev`(localhost:5173). 점검: `npm run check`, `npm run build`. 둘 다 통과하는 상태에서 끝났다.
- 프로젝트는 git 저장소가 아니다. 큰 변경 전에 `git init`과 첫 커밋을 제안할 것(사용자 확인 후).
- 브라우저 확인 방법과 점검용 서버(127.0.0.1:5174)는 [`../standards/workflow.md`](../standards/workflow.md)를 따른다.

## 다음 세션 작업 목록

### A. 대사와 문구 (먼저 처리, 위험 낮음)

1. 줄바꿈 2판 적용: 점검 스크립트를 2판 기준으로 바꾸고 모든 대사를 다시 나눈다. 사용자가 짚은 대사: 창 2:4~5, 창 3:14, 창 3:22, 창 3:15 뒤 대천사 대사("꼭 기억해 두세요.\n나중에…"). → [dialogue.md](../standards/dialogue.md)
2. 대사 본문에 `text-wrap: balance`를 넣는다. → [dialogue.md](../standards/dialogue.md)
3. '하나님이' → '하나님께서'(서술어 높임 포함). 모든 대사에 적용한다. → [dialogue.md](../standards/dialogue.md)
4. '봐요' → '보아요' 같은 본딧말 권유로 통일한다. → [dialogue.md](../standards/dialogue.md)
5. `FALL.serpent`의 대천사 대사 "{name}님… 우리는 이 일을 바꿀 수 없어요. 함께 지켜봐요." 삭제.
6. 지상 꾸미기 안내 문구 줄바꿈: "땅에서도 사람들 눈에는 보이지 않아요.\n여러 시대를 함께 걸을 모습을 골라 주세요."(`src/main.js`의 `runDressingRoom`)
7. 퀘스트 목표 문구를 행동 동사로: "비손 강으로 이동하기" 등. "열매 1 모으기" 금지. → [ui.md](../standards/ui.md)

### E. 에덴 퀘스트 재설계 → [quests-and-staging.md](../standards/quests-and-staging.md)

17. 동물: 아담이 지음 받기 전부터 동산을 돌아다닌다(지금은 `showAnimals`에서 나타남).
18. 동물 기록을 인터랙티브하게: 곁에 머무르면 게이지 → 아담이 이름을 지어 주는 짧은 장면 → 도감 카드. "바이블로그에 기록했어요: ○○" 알림은 없앤다.
19. 열매: 실제 열매(무화과, 석류, 포도, 올리브, 대추야자 등)로 바꾸고, 따면 바구니로 날아가 담기는 연출. 에덴 열매 종류는 본문에 없으니 각색임을 밝힌다.

### F. 에덴 연출 → [quests-and-staging.md](../standards/quests-and-staging.md)

20. 동산 가운데 두 나무를 말할 때(창 2:9 대사) 카메라가 가운데로 가며 선악을 알게 하는 나무에 스포트라이트.
21. 하와: 화면 전환 없이, 아담이 깊이 잠들고 옆구리에서 빛이 나와 하와가 되는 연출(지금은 `fade` 후 `showEve`).
22. 뱀이 하와 발밑에 깔려 보이는 문제: 위치와 높이를 분리.
23. 하와가 먹고 아담에게 실제로 건네는 동작(지금은 나무에서 열매가 각각 날아감).
24. 가죽옷 장면: 숨은 나무 뒤에서 두 사람이 나온 뒤 입히는 장면이 보이게.
25. 추방: 동쪽 문 밖의 바깥 세상(거친 땅, 가시덤불)으로 걸어 나가는 느낌. 지금은 바다 쪽으로 걸어가 사라진다.

## 알려진 문제와 주의

- 자동화 브라우저에서 화면 갱신이 느리다. 퀘스트 확인은 `__dev.player.position.set(...)`으로 순간 이동한다.
- 뱀 장면 이후(숨기·추방)는 마지막 수정 뒤 끝까지 화면으로 보지 않았다.
- 휴대폰 폭에서 지상 꾸미기 화면(아래 시트)은 직접 확인하지 않았다.
- 사용자의 실제 저장값은 localhost:5173에 있다. 점검은 127.0.0.1:5174에서만 한다.
