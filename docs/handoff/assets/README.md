# 인계용 시각 근거

- `approved-art-A.png`: 사용자가 선택한 따뜻하고 성숙한3D의 **아트 레퍼런스**다. 이미지 생성으로 만든 콘셉트이며 실제 게임 캡처가 아니다. 화풍·비례·빛·재질을 판단하는 기준이고 픽셀 복제 목표는 아니다.
- `well-pc-known-failure.png/json`:1280×720 실제 게임. 대사를 키로 넘기고 WASD로 늙은 종에게 걸어간 뒤, 리브가가 우물에 등장한 첫 대사다. 배우 머리가 화면 위로 잘려 실패했다.
- `well-mobile-last-check.png/json`:390×844의 같은 실제 진입 흐름. 필요한 배우·대사 그늘 제외·천사/관찰자 겹침0을 당시 검사에서 통과했다. 전체 스테이지·실기기·최종 아트 수용을 뜻하지 않는다.
- `well-pc-repeat-pass.png/json`: 인계 도구를 독립 QA서버에서 실행한 후속1280×720의 단일 통과다. 카메라 코드는 이전과 같으며 관찰자/천사가 서 있는 자리가 달라졌다. 실패 조건은 미확인이므로 이전 실패를 지우지 않는다. JSON에는 실제 카메라/배우 세계좌표도 있다.
- `manifest.json`: 근거 일곱 파일의 바이트 수와 SHA256이다. 로컬 원본과 바이트가 같다. 이미지에는 테스트용 게임 화면만 있으며 계정·대화·비밀값은 없다.

실제 게임은 Three.js 인물·지형·소품을 렌더한다. 이 PNG를 배경이나 인물 대신 붙여 결과를 흉내 내지 않는다. 이미 만들어 둔 에셋을 재사용하는 데 새 이미지 모델 호출은 필요 없다.
