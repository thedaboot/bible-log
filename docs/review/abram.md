- [ ] **대천사**: 언덕마다 올라가 별 아래 잠시 서 보아요. / 몇 개까지 셀 수 있을까요? `abram.vision`
- [ ] **대천사**: 백까지 세었는데, 그 사이에 별이 또 돋았어요. `abram.stars`
- [ ] **대천사**: 아이 하나 없는데도 아브람은 그 말씀을 믿었어요. / 별을 세던 밤의 말씀을 함께 돌아볼까요? `abram.stars`

## 막간: 사래

사건의 흐름을 바꾸지 않는지, 선택지가 모두 좋은 행동인지, 자라는 열매가 맞는지 본다.

- [ ] **서술**: 사래가 장막 앞에서 맷돌에 보리를 갈다가 손을 멈추었다. _(근거: 창 12:8 장막, 창 18:6 가루 반죽)_
- [ ] **사래**: 길에서 늘 앞서 걷던 분이군요. / 하란에서 여기까지 발이 많이 아프셨지요? _(근거: 막간: 인물이 관찰자를 알아본다, 창 12:5)_

**선택 1**

- [ ] 「발은 사래님이 더 아프죠?」 → 친절
  - [ ] **사래**: 들켰네요. 신발 끈 자리가 다 까졌어요. / 그래도 장막 접는 일은 이제 눈 감고도 해요. _(근거: 창 12:5~8 옮겨 다님)_
- [ ] 「(맷돌을 대신 돌린다)」 → 선함
  - [ ] **서술**: 맷돌이 생각보다 무거웠다. 사래가 웃으며 손잡이를 같이 잡아 주었다. _(근거: 창 12:8 장막 살림)_
- [ ] 「갈 곳도 모르고 떠나셨죠?」 → 신실
  - [ ] **사래**: 짐 쌀 때가 제일 곤란했어요. 어느 날씨에 맞출지 몰라서요. / 그래도 남편이 들은 목소리를 나도 믿어 보기로 했어요. _(근거: 히 11:8~9 갈 바를 알지 못하고 나감, 히 11:11)_
- [ ] 「함께 기다릴게요.」 → 인내 · 신실 새싹 이상에서 열림
  - [ ] **사래**: 고마워요. 기다리는 일은 혼자 하면 더 길거든요. _(근거: 창 11:30, 히 11:11 약속하신 이를 미쁘신 줄 앎)_

- [ ] **사래**: 큰 민족을 이루게 하신다는데, / 우리 장막엔 아직 아기 울음소리 하나 없어요. _(근거: 창 11:30 잉태하지 못함, 창 12:2)_
- [ ] **사래**: 그래도 롯이 아들처럼 곁에 있어 줘서 다행이에요. _(근거: 창 12:4~5 롯이 함께 감)_

**선택 2**

- [ ] 「큰 민족이면 이름 짓기 바쁘겠어요.」 → 기쁨
  - [ ] **사래**: 어머, 그러네요. 첫 아이 이름부터 정해 둘까 봐요. / 오늘 밤은 별이 조금 덜 차가워 보이네요. _(근거: 창 12:2 큰 민족, 창 15:5)_
- [ ] 「그 마음 많이 아프셨겠어요.」 → 사랑
  - [ ] **사래**: 여러 해 동안 아무에게도 말 못 했어요. 들어 줘서 고마워요. _(근거: 창 11:30)_
- [ ] 「롯 목소리가 제일 크던데요.」 → 화평
  - [ ] **사래**: 맞아요, 양 떼를 몰 때면 골짜기가 다 울려요. / 남편은 그 소리를 들으면 웃어요. _(근거: 창 13:5 롯도 양과 소와 장막이 있었음)_

- [ ] **사래**: 밤이 깊었네요. 남편이 또 하늘을 보러 나가겠어요. _(근거: 창 15:5로 이어짐)_

## 도감 메모

본문 사실(fact·ref)은 장절과 맞는지, 관찰자 메모(memo)는 본문을 넘어서지 않는지 본다.

- [ ] **아브라함** (창 12:4) 말씀을 따라 하란을 떠난 믿음의 조상 — 메모: 아브람이라 불리다가 많은 민족의 아버지라는 이름을 받았다(창 17:5).
- [ ] **사라** (창 17:15) 아브라함의 아내, 이삭의 어머니 — 메모: 처음 만났을 때는 사래였다. 맷돌을 돌리며 웃음을 잃지 않았다.
- [ ] **롯** (창 12:4) 아브람의 조카, 함께 길을 떠난 사람 — 메모: 양 떼를 몰 때 목소리가 가장 컸다.
- [ ] **하란** (창 12:4) 아브람이 일흔다섯 살에 떠난 곳 — 메모: 흙벽돌 집을 뒤로하고 길을 나섰다.
- [ ] **모레 상수리나무** (창 12:6~7) 세겜 땅에서 아브람이 처음 제단을 쌓은 곳 — 메모: 그늘이 넓어 무리가 다 쉬어 갈 수 있었다.
- [ ] **상수리나무 잎** (창 12:6) 세겜 모레 상수리나무 — 메모: 처음 제단을 쌓은 나무 아래에서 주운 잎.
- [ ] **복이 되리라** (창 12:2) 큰 민족을 이루고 이름을 크게 하리니 너는 복이 될 것이다 — 메모: 바벨에서 사람들이 스스로 높이려던 이름을 하나님이 아브람에게 주셨다.
- [ ] **믿음과 의** (창 15:6) 아브람이 여호와를 믿으니 이를 그의 의로 여기셨다 — 메모: 셀 수 없는 별 아래에서 들은 말씀이다.
