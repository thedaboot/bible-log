## 막간: 벽돌 굽는 이

사건의 흐름을 바꾸지 않는지, 선택지가 모두 좋은 행동인지, 자라는 열매가 맞는지 본다.

- [ ] **서술**: 가마 앞에서 벽돌 굽는 이가 이마의 땀을 닦았다. _(근거: 창 11:3 벽돌을 굽자)_
- [ ] **벽돌 굽는 이**: 처음 보는 얼굴이네. 일하러 왔소? / 하루에 벽돌 삼백 장은 구워야 탑이 자라오. _(근거: 막간: 인물이 관찰자를 알아본다, 창 11:3)_

**선택 1**

- [ ] 「삼백 장이나요?」 → 인내
  - [ ] **벽돌 굽는 이**: 어제는 삼백열 장이었소. 가마 불을 밤새 지키느라 눈이 따갑소. _(근거: 창 11:3 굽자)_
- [ ] 「(벽돌을 함께 나른다)」 → 친절
  - [ ] **서술**: 구운 벽돌은 아직 따뜻했다. / 벽돌 굽는 이가 장갑 대신 천 조각을 건네주었다. _(근거: 창 11:3 벽돌)_
- [ ] 「탑은 왜 쌓아요?」 → 신실
  - [ ] **벽돌 굽는 이**: 꼭대기가 하늘에 닿으면 우리 이름이 높아진다더군. / 위에서 그렇게 정했소. _(근거: 창 11:4 이름을 내자)_
- [ ] 「불 지키는 거 대신할게요.」 → 선함 · 친절 새싹 이상에서 열림
  - [ ] **벽돌 굽는 이**: 정말이오? 그럼 잠깐 눈 좀 붙이겠소. 불이 하얘지면 나를 깨우시오. _(근거: 창 11:3)_

- [ ] **벽돌 굽는 이**: 우리 고향은 저 동쪽이오. 거기선 흩어져 양을 쳤지. _(근거: 창 11:2 동쪽에서 옮김)_
- [ ] **벽돌 굽는 이**: 여기 모이니 좋긴 한데, 요즘은 탑만 보고 사오. _(근거: 창 11:4 흩어짐을 면하자)_

**선택 2**

- [ ] 「고향 이야기 더 들려주세요.」 → 사랑
  - [ ] **벽돌 굽는 이**: 봄이면 언덕마다 새끼 양이 뛰어다녔소. / 그 소리를 들은 지 오래됐구려. _(근거: 창 4:2 양 치는 일, 창 11:2)_
- [ ] 「쉬는 날도 있어요?」 → 화평
  - [ ] **벽돌 굽는 이**: 탑이 다 서면 쉰다고들 하오. 그게 언제일지는 아무도 모르지. _(근거: 창 11:4~6)_
- [ ] 「벽돌이 참 반듯해요.」 → 기쁨
  - [ ] **벽돌 굽는 이**: 틀을 내가 짰소. 모서리가 안 깨지게 진흙에 짚을 섞지. _(근거: 창 11:3, 출 5:7 벽돌과 짚)_

- [ ] **벽돌 굽는 이**: 어이쿠, 불이 꺼지겠소. 이야기 고맙소. _(근거: 창 11:3)_

## 도감 메모

본문 사실(fact·ref)은 장절과 맞는지, 관찰자 메모(memo)는 본문을 넘어서지 않는지 본다.

- [ ] **벽돌 굽는 이** (창 11:3) 시날 들판에서 벽돌을 구워 탑을 쌓던 사람들 — 메모: 본문에 이름이 없는 일꾼이다. 가마 불을 밤새 지켰다(각색 인물).
- [ ] **시날 땅** (창 11:2) 사람들이 동쪽에서 옮겨 와 머문 들판 — 메모: 돌이 귀해 진흙을 구워 벽돌을 만들었다.
- [ ] **바벨** (창 11:9) 여호와께서 온 땅의 언어를 뒤섞으신 곳 — 메모: 꼭대기를 하늘에 닿게 하려던 탑이 거기서 멈추었다.
- [ ] **구운 벽돌** (창 11:3) 사람들이 돌 대신 쓴 벽돌 — 메모: 모서리가 반듯한 벽돌 한 장. 이 스테이지의 기념물이다.
- [ ] **흩으심** (창 11:9) 여호와께서 거기서 언어를 뒤섞고 사람들을 온 땅에 흩으셨다 — 메모: 자기 이름을 내려던 일이 흩어짐으로 끝났다.
