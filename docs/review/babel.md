## 막간: 벽돌 굽는 이

사건의 흐름을 바꾸지 않는지, 선택지가 모두 좋은 행동인지, 자라는 열매가 맞는지 본다.

- [ ] **서술**: 가마 앞에서 벽돌 굽는 이가 이마의 땀을 닦았다. _(근거: 창 11:3 벽돌을 굽자)_
- [ ] **벽돌 굽는 이**: 처음 보는 얼굴이구려. 일하러 왔소? / 하루에 벽돌 삼백 장은 구워야 탑이 자라오. _(근거: 막간: 인물이 관찰자를 알아본다, 창 11:3)_

**선택 1**

- [ ] 「삼백 장이면 허리 아프시겠어요.」 → 인내
  - [ ] **벽돌 굽는 이**: 허리보다 눈이 먼저 맵소. 종일 가마 연기를 쐬니. / 그래도 삼백 장이라야 담 한 줄 반이오. 한 층은 아직 멀었지. _(근거: 창 11:3 굽자)_
- [ ] 「(벽돌을 맨손으로 든다)」 → 친절
  - [ ] **서술**: 갓 구운 벽돌은 생각보다 뜨거웠다. / 벽돌 굽는 이가 웃으며 손에 감을 천 조각을 건넸다. _(근거: 창 11:3 벽돌을 굽자)_
  - [ ] **벽돌 굽는 이**: 맨손은 다들 첫날만 하오. 나도 그렇게 배웠지. _(근거: 창 11:3)_
- [ ] 「하늘에 진짜 닿아요?」 → 신실

- [ ] 「불은 제가 볼게요. 주무세요.」 → 선함 · 친절 새싹 이상에서 열림
  - [ ] **벽돌 굽는 이**: 정말이오? 불이 하얘지면 깨우시오. / 노래지면 괜찮고, 빨개지면… 그냥 나를 깨우시오. _(근거: 창 11:3 불에 굽자)_

- [ ] **벽돌 굽는 이**: 우리 고향은 여기서 먼 곳이오. 거기선 흩어져 양을 쳤지. _(근거: 창 11:2 동방으로 옮기다가)_
- [ ] **벽돌 굽는 이**: 여기 모이니 좋긴 한데, 요즘은 탑만 보고 사오. _(근거: 창 11:4 흩어짐을 면하자)_

## 도감 메모

본문 사실(fact·ref)은 장절과 맞는지, 관찰자 메모(memo)는 본문을 넘어서지 않는지 본다.

- [ ] **벽돌 굽는 이** (창 11:3) 시날 들판에서 벽돌을 구워 탑을 쌓던 사람들 — 메모: 본문에 이름이 없는 일꾼이다. 가마 불을 밤새 지켰다(각색 인물).
- [ ] **시날 땅** (창 11:2) 사람들이 동방으로 옮기다가 머문 들판 — 메모: 돌이 귀해 진흙을 구워 벽돌을 만들었다.
- [ ] **바벨** (창 11:9) 여호와께서 온 땅의 언어를 뒤섞으신 곳 — 메모: 꼭대기를 하늘에 닿게 하려던 탑이 거기서 멈추었다.
- [ ] **구운 벽돌** (창 11:3) 사람들이 돌 대신 쓴 벽돌 — 메모: 모서리가 반듯한 벽돌 한 장을 기념으로 챙겼다.
- [ ] **흩으심** (창 11:9) 여호와께서 거기서 언어를 뒤섞고 사람들을 온 땅에 흩으셨다 — 메모: 자기 이름을 높이려던 일은 흩어짐으로 끝났다.
