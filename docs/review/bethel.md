사건의 흐름을 바꾸지 않는지, 선택지가 모두 좋은 행동인지, 자라는 열매가 맞는지 본다.

- [ ] **서술**: 야곱이 돌을 받아 들고 한참 만지작거렸다. _(근거: 창 28:11)_

**선택 1**

- [ ] 「자꾸 뒤를 돌아보시네요.」 → 친절
  - [ ] **야곱**: 보였소? 형님이 쫓아올까 봐 하루 종일 그랬소. _(근거: 창 27:41 에서가 죽이려 함)_
- [ ] 「(곁에 불을 지펴 준다)」 → 선함
  - [ ] **서술**: 마른 덤불에 불이 붙자 야곱의 얼굴이 조금 풀렸다. / 그가 두 손을 불 쪽으로 내밀었다. _(근거: 창 28:11 해가 진 들)_
- [ ] 「하란은 얼마나 멀어요?」 → 인내
  - [ ] **야곱**: 걸어서 한 달은 가야 하오. 외삼촌 라반이 반겨 주면 좋겠소. _(근거: 창 28:2, 창 29:1)_
- [ ] 「혼자가 아니에요.」 → 신실 · 친절 새싹 이상에서 열림

- [ ] **야곱**: 아버지를 속였소. 형님 옷을 입고, 손에 염소 가죽까지 두르고. _(근거: 창 27:15~24)_
- [ ] **야곱**: 축복은 받았는데, 정작 이렇게 쫓겨 다니는 몸이오. _(근거: 창 27:41~43)_
