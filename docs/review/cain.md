## 막간: 아벨

사건의 흐름을 바꾸지 않는지, 선택지가 모두 좋은 행동인지, 자라는 열매가 맞는지 본다.

- [ ] **서술**: 해가 지자 아벨이 우리 문을 닫고 손가락을 접어 가며 양을 세었다. _(근거: 창 4:2 양 치는 자)_
- [ ] **아벨**: 당신이 몰아 준 거요? 오늘은 한 마리도 안 헤매고 들어왔소. _(근거: 막간: 인물이 관찰자를 알아본다)_
- [ ] **아벨**: 얼룩귀는 늘 마지막이오. 풀 한 입만 더 먹겠다고 버티는 녀석이지. _(근거: 창 4:2 양 치는 자)_

**선택 1**

- [ ] 「한 마리도 안 빠졌어요!」 → 기쁨
  - [ ] **아벨**: 다섯 마리에 어린양 하나, 다 있소. 이런 날은 나도 잠이 잘 오지. _(근거: 창 4:2 양 치는 자)_
- [ ] 「(어린양을 쓰다듬는다)」 → 온유
  - [ ] **서술**: 어린양이 손바닥에 머리를 비볐다. / 아벨이 웃으며 털에 붙은 풀씨를 떼어 주었다. _(근거: 창 4:2, 사 40:11 어린 양을 품에 안는 목자)_
- [ ] 「저녁마다 세시는 거예요?」 → 인내
  - [ ] **아벨**: 날마다 세오. / 하나라도 모자라면 찾을 때까지 들판에서 밤을 새야 하니. _(근거: 창 4:2 양 치는 자)_
- [ ] 「내일은 같이 셀게요.」 → 친절 · 기쁨 새싹 이상에서 열림
  - [ ] **아벨**: 좋소. 그럼 당신은 저쪽 줄부터 세시오. / 얼룩귀가 또 줄을 바꿀 테니 잘 보시오. _(근거: 창 4:2)_

- [ ] **아벨**: 내일은 형님과 함께 여호와께 드릴 것을 가져가오. _(근거: 창 4:3~4)_
- [ ] **아벨**: 나는 이 어린양을 드리려 하오. / 올봄에 가장 먼저 났고, 가장 튼튼하오. _(근거: 창 4:4 양의 첫 새끼, 히 11:4)_
- [ ] **아벨**: 형님은 밭에서 거둔 것을 드린다더군. _(근거: 창 4:3 땅의 소산)_

**선택 2**

- [ ] 「첫 새끼부터 드리는군요.」 → 신실
  - [ ] **아벨**: 좋은 것을 주신 분께 남은 것을 드릴 수는 없지 않소. _(근거: 창 4:4 첫 새끼와 그 기름, 히 11:4 더 나은 제사)_
- [ ] 「어린양한테는 말했어요?」 → 친절
  - [ ] **아벨**: 아직이오. 오늘 밤엔 풀을 한 줌 더 주었소. / 아깝지 않다면 거짓말이지. _(근거: 창 4:4, 출 13:2 처음 난 것)_
- [ ] 「형님 밭엔 뭐가 났어요?」 → 화평
  - [ ] **아벨**: 보리가 제법 여물었소. / 내일은 형님이 곡식 단을, 나는 어린양을 안고 가오. _(근거: 창 4:3~4 땅의 소산과 양의 첫 새끼(곡식 종류는 각색))_
- [ ] 「형님 몫도 같이 기도할게요.」 → 사랑 · 온유 새싹 이상에서 열림
  - [ ] **아벨**: 고맙소. 형님은 요즘 엉겅퀴를 뽑느라 손이 성한 날이 없소. _(근거: 창 3:17~18 가시덤불과 엉겅퀴, 창 4:2 땅을 일구는 자)_

- [ ] **아벨**: 해가 다 졌구려. 내일은 일찍 나서야 하오. _(근거: 창 4:3~4 제물을 가져가기 전날)_

- [ ] **죄를 다스려라** (창 4:7) 죄가 문 앞에 엎드려 있으나 너는 죄를 다스려야 한다 — 메모: 화가 난 가인에게 하나님이 먼저 말을 거셨다.
