## 막간: 아담

사건의 흐름을 바꾸지 않는지, 선택지가 모두 좋은 행동인지, 자라는 열매가 맞는지 본다.

- [ ] **서술**: 해가 기울 무렵, 아담이 강가에 앉아 동물들을 바라보았다. _(근거: 창 2:20)_
- [ ] **아담**: 거기 누구요? 오늘 내내 내 곁에 있었던 것 같은데. _(근거: 막간: 인물이 관찰자를 알아본다)_
- [ ] **아담**: 오늘 이름을 몇이나 지었는지 모르겠소. / 데려오시는 대로 불렀더니 그게 다 제 이름이 되더군. _(근거: 창 2:19 "아담이 각 생물을 부르는 것이 곧 그 이름이 되었더라")_

**선택 1**

- [ ] 「이름마다 꼭 어울렸어요!」 → 기쁨
  - [ ] **아담**: 그렇소? 사자는 부르자마자 갈기를 털더군. / 제 이름인 줄 아는 것 같았소. _(근거: 창 2:19)_
- [ ] 「(말없이 곁에 앉는다)」 → 화평
  - [ ] **서술**: 아담도 더 말하지 않고 강물에 발을 담갔다. / 멀리서 양이 한 번 울었다. _(근거: 창 2:10 동산을 적시는 강)_
- [ ] 「오래 바라보고 지어 주셨죠.」 → 인내
  - [ ] **아담**: 코끼리 앞에서는 한참 서 있었소. / 코가 그렇게 긴 짐승은 처음 봤으니까. _(근거: 창 2:19 "무엇이라 부르는지 보시려고")_
- [ ] 「이름들을 함께 불러 봐요!」 → 사랑 · 기쁨 새싹 이상에서 열림
  - [ ] **아담**: 좋소. 사자야! 양아! 코끼리야! _(근거: 창 2:19~20)_
  - [ ] **아담**: 하하, 둘이 부르니 녀석들이 다 돌아보는구려. _(근거: 창 2:19~20)_

- [ ] **아담**: 그런데 짐승들은 다 짝이 있더군. / 사자 곁엔 암사자가, 양 곁엔 다른 양이. _(근거: 창 1:24~25 "그 종류대로")_
- [ ] **아담**: 나만 혼자요. 나와 꼭 맞는 이는 아직 없소. _(근거: 창 2:20)_

**선택 2**

- [ ] 「오늘 하루는 참 좋았어요.」 → 기쁨
  - [ ] **아담**: 그건 그렇소. 강물도 나무도 짐승들도 다 좋았지. / 이 좋은 걸 같이 볼 이가 있으면 좋겠소. _(근거: 창 1:31, 창 2:18)_
- [ ] 「지금은 제가 곁에 있을게요.」 → 화평
  - [ ] **아담**: 고맙소. 오늘 저녁은 혼자 앉아 있지 않아도 되겠구려. _(근거: 창 2:18)_
- [ ] 「하나님께서 하실 일을 기다려 봐요.」 → 인내
  - [ ] **아담**: 기다려 보지. / 짐승들도 하나님께서 데려오셨으니 내게 맞는 이도 데려오실지 모르지. _(근거: 창 2:19, 창 2:22 "그를 아담에게로 이끌어 오시니")_
- [ ] 「하나님은 말씀하신 대로 하세요.」 → 신실 · 인내 새싹 이상에서 열림
  - [ ] **아담**: 그렇지. 먹어도 된다고 하신 열매는 다 달았소. / 하신 말씀이 틀린 적이 없었지. _(근거: 창 2:16)_

- [ ] **아담**: 눈이 자꾸 감기는구려. 오늘은 여기서 좀 쉬어야겠소. _(근거: 창 2:21 잠들기 직전)_

본문 사실(fact·ref)은 장절과 맞는지, 관찰자 메모(memo)는 본문을 넘어서지 않는지 본다.

- [ ] **하와** (창 3:20) 모든 산 사람의 어머니 — 메모: 아담 곁에서 동산의 열매를 함께 돌보았다.
- [ ] **사자** (창 2:19) 아담이 이름을 지어 준 들짐승 — 메모: 갈기가 바람에 흔들려도 아담 곁에서는 순했다.
- [ ] **양** (창 2:20) 아담이 이름을 지어 준 가축 — 메모: 부르면 고개를 들고 천천히 다가왔다.
- [ ] **코끼리** (창 2:19) 아담이 이름을 지어 준 들짐승 — 메모: 걸음은 느렸지만 땅이 울릴 만큼 컸다.
- [ ] **사슴** (창 2:19) 아담이 이름을 지어 준 들짐승 — 메모: 가지 친 뿔을 숙이고 강가의 풀을 뜯었다.
- [ ] **말** (창 2:19) 아담이 이름을 지어 준 들짐승 — 메모: 긴 갈기를 날리며 동산을 한 바퀴 돌았다.
- [ ] **곰** (창 2:19) 아담이 이름을 지어 준 들짐승 — 메모: 둥근 귀를 쫑긋 세우고 아담을 바라보았다.
- [ ] **무화과나무** (창 3:7) 두 사람이 잎을 엮어 몸을 가린 나무 — 메모: 넓은 잎 아래에 열매가 숨어 있었다.
- [ ] **석류나무** (출 28:33) 대제사장 옷단에 수놓은 열매 — 메모: 붉은 열매 안에 알갱이가 가득했다.
- [ ] **포도나무** (민 13:23) 정탐꾼이 메고 온 큰 포도송이 — 메모: 송이가 무거워 가지가 휘어 있었다.
- [ ] **올리브나무** (신 8:8) 약속의 땅에 나는 열매 — 메모: 잎 뒷면이 은빛으로 반짝였다.
- [ ] **대추야자나무** (신 34:3) 종려나무 성읍 여리고 — 메모: 높은 꼭대기에 열매가 주렁주렁 달렸다.
- [ ] **뱀** (창 3:1) 들짐승 가운데 가장 간교했다 — 메모: 말은 부드러웠지만 하나님의 말씀을 비틀었다.
- [ ] **에덴 동산** (창 2:8) 하나님께서 동쪽에 일구신 동산 — 메모: 보기에 아름답고 먹기에 좋은 나무가 가득했다.
- [ ] **비손 강** (창 2:11) 금이 나는 하윌라 땅을 두른 강 — 메모: 물빛 아래로 모래가 반짝였다.
- [ ] **기혼 강** (창 2:13) 구스 온 땅을 두른 강 — 메모: 굽이굽이 동산 가장자리를 돌아 흘렀다.
- [ ] **힛데겔 강** (창 2:14) 앗수르 동쪽으로 흐른 강 — 메모: 물살이 빨라 다리 위에서도 소리가 들렸다.
- [ ] **유브라데 강** (창 2:14) 에덴에서 갈라진 넷째 강 — 메모: 넓고 잔잔하게 흘러 나갔다.
- [ ] **무화과 잎** (창 3:7) 두 사람이 엮어 몸을 가린 잎 — 메모: 에덴을 떠나며 받은 기념물. 가죽옷을 지어 입히신 일도 함께 기억한다.
- [ ] **흙과 생명의 숨** (창 2:7) 흙으로 사람을 지으시고 생명의 숨을 불어넣으셨다 — 메모: 사람이 살아 있는 존재가 된 처음 순간이다.
- [ ] **여자의 후손** (창 3:15) 여자의 후손이 뱀의 머리를 상하게 한다 — 메모: 대천사가 꼭 기억해 두라고 한 약속이다.
