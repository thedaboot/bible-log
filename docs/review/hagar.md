## 막간: 하갈

사건의 흐름을 바꾸지 않는지, 선택지가 모두 좋은 행동인지, 자라는 열매가 맞는지 본다.

- [ ] **서술**: 하갈이 샘물에 손을 담그고 오래 앉아 있었다. _(근거: 창 16:7 샘 곁)_
- [ ] **하갈**: 당신도 여기서 길을 잃었나요? / 이 광야에 나 말고 누가 있을 줄은 몰랐어요. _(근거: 막간: 인물이 관찰자를 알아본다, 창 16:7)_

**선택 1**

- [ ] 「물 좀 드세요.」 → 친절
  - [ ] **서술**: 하갈이 두 손으로 물을 떠 마셨다. / 그제야 입술의 갈라진 자리가 보였다. _(근거: 창 16:7 샘)_
- [ ] 「다치신 데는 없어요?」 → 사랑
  - [ ] **하갈**: 발바닥이 다 갈라졌어요. 그래도 마음보다는 덜 아파요. _(근거: 창 16:6 학대를 피해 도망)_
- [ ] 「(말없이 곁에 앉는다)」 → 화평
  - [ ] **서술**: 샘물 흐르는 소리만 들렸다. 하갈이 조금씩 숨을 고르게 쉬었다. _(근거: 창 16:7)_
- [ ] 「보고 계신 분이 있었네요.」 → 신실 · 친절 새싹 이상에서 열림
  - [ ] **하갈**: 그래요. 나 같은 종의 이름까지 불러 주셨어요. _(근거: 창 16:8 하갈아, 창 16:13)_

- [ ] **하갈**: 돌아가라고 하셨어요. 솔직히 무서워요. _(근거: 창 16:9)_
- [ ] **하갈**: 그래도 아이 이름을 먼저 지어 주셨으니, / 이 아이는 잊지 않으실 거예요. _(근거: 창 16:11 이스마엘(하나님이 들으심))_

**선택 2**

- [ ] 「이름을 미리 받은 아이네요.」 → 기쁨
  - [ ] **하갈**: 그래요, 태어나기도 전에 이름이 생겼어요. / 하나님께서 들으신다는 뜻이래요. 울 때마다 부르려고요. _(근거: 창 16:11 이스마엘의 뜻)_
- [ ] 「돌아가는 길 같이 가요.」 → 선함
  - [ ] **하갈**: 샘에서 장막까지 사흘 길이에요. 반만 같이 가도 훨씬 덜 무섭겠어요. _(근거: 창 16:9 돌아가라, 창 16:7 술 길)_
- [ ] 「천천히 가셔도 돼요.」 → 인내
  - [ ] **하갈**: 그럴게요. 해가 지면 이 샘가에서 하룻밤 더 자고 가요. _(근거: 창 16:14 브엘라해로이)_

- [ ] **하갈**: 이 샘 이름을 잊지 말아요. 나를 보시는 분의 샘이에요. _(근거: 창 16:13~14)_

## 도감 메모

본문 사실(fact·ref)은 장절과 맞는지, 관찰자 메모(memo)는 본문을 넘어서지 않는지 본다.

- [ ] **하갈** (창 16:1) 사래의 애굽인 여종, 이스마엘의 어머니 — 메모: 광야에서 자기 이름을 불러 주신 분을 만났다.
- [ ] **이스마엘** (창 16:11) 하나님이 들으신다는 이름의 아들 — 메모: 광야에서 자라 활 쏘는 사람이 되었다(창 21:20).
- [ ] **브엘라해로이** (창 16:14) 나를 살피시는 살아 계신 이의 우물 — 메모: 마른 땅 사이에 풀빛이 돋은 샘이었다.
- [ ] **브엘세바 광야** (창 21:14) 하갈과 아이가 물이 떨어져 헤맨 광야 — 메모: 덤불 그늘 말고는 숨을 곳이 없었다.
- [ ] **가죽 부대** (창 21:14) 아브라함이 하갈에게 준 물 부대 — 메모: 샘물을 가득 채워 아이에게 건넨 부대. 이 스테이지의 기념물이다.
- [ ] **살피시는 하나님** (창 16:13) 하갈이 자기에게 말씀하신 여호와를 나를 살피시는 하나님이라 불렀다 — 메모: 아무도 보지 않는다고 여긴 자리에서 들은 이름이다.
