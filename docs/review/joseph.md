- [ ] **요셉**: 당신은 도단의 들에서부터 내 곁에 있었지요. / 여기까지 따라온 사람은 당신뿐입니다. _(근거: 막간: 인물이 관찰자를 알아본다, 창 37:17)_

**선택 1**

  - [ ] **요셉**: 원망만 하기엔 하루가 너무 길더군요. 그래서 할 일을 찾았습니다. _(근거: 창 39:20~22)_
- [ ] 「관원장, 술잔 드느라 잊었나 봐요.」 → 인내
  - [ ] **요셉**: 하하, 그런가 봅니다. 벌써 한 해가 지났지요. / 그래도 꿈을 풀어 주신 분이 잊으실 리는 없지요. _(근거: 창 40:14, 40:23, 41:1)_
- [ ] 「(빵을 반으로 나눈다)」 → 선함
  - [ ] **서술**: 요셉이 웃으며 반쪽을 받아 들었다. / 옆 죄수가 그 모습을 보고 자기 빵도 반으로 갈랐다. _(근거: 창 39:22~23)_
- [ ] 「그분은 옥에도 계시잖아요.」 → 신실 · 인내 새싹 이상에서 열림
  - [ ] **요셉**: 압니다. 구덩이에도 계셨으니까요. _(근거: 창 39:21 여호와께서 함께 계심)_

- [ ] **요셉**: 아버지가 보고 싶습니다. 동생 베냐민도요. _(근거: 창 35:18 베냐민, 창 43:29~30)_
- [ ] **요셉**: 형님들도 가끔 생각납니다. 미운데도 그렇습니다. _(근거: 창 42:24 돌이켜 울었다)_

## 도감 메모

본문 사실(fact·ref)은 장절과 맞는지, 관찰자 메모(memo)는 본문을 넘어서지 않는지 본다.

- [ ] **요셉** (창 41:41) 야곱이 사랑한 아들, 애굽을 다스린 이 — 메모: 옥에서도 죄수들의 빵을 나누고 맨 마지막에 앉았다.
- [ ] **바로** (창 41:15) 꿈을 꾸고 요셉에게 풀이를 들은 애굽 왕 — 메모: 요셉을 하나님의 영에 감동된 사람이라 불렀다.
- [ ] **술 맡은 관원장** (창 40:9) 옥에서 요셉에게 꿈 풀이를 들은 신하 — 메모: 두 해 동안 잊었다가 바로 앞에서 요셉을 기억해 냈다.
- [ ] **도단** (창 37:17) 형들이 양을 치다 요셉을 판 들 — 메모: 빈 구덩이 하나가 들 가운데 있었다.
- [ ] **애굽** (창 39:1) 요셉이 종으로 팔려 가 다스리는 자가 된 땅 — 메모: 옥에서 궁정까지, 요셉이 걸은 길은 끊기지 않고 이어졌다.
- [ ] **살진 암소** (창 41:26) 바로의 꿈에서 일곱 해의 풍년을 뜻한 소 — 메모: 나일 강가에서 갈밭 풀을 뜯던 소들이었다.
- [ ] **충실한 이삭** (창 41:22) 한 줄기에 일곱 이삭이 충실하게 맺힌 곡식 — 메모: 마른 이삭이 충실한 이삭을 삼켰다.
- [ ] **채색옷 실** (창 37:3) 야곱이 요셉에게 지어 입힌 채색옷 — 메모: 구덩이 곁에 떨어진 옷의 실 한 가닥. 이 스테이지의 기념물이다.
- [ ] **형통하게 하심** (창 39:23) 여호와께서 요셉과 함께하사 그가 하는 일을 형통하게 하셨다 — 메모: 옥 안에서 들은 말씀이다.
