## 막간: 아브라함

사건의 흐름을 바꾸지 않는지, 선택지가 모두 좋은 행동인지, 자라는 열매가 맞는지 본다.

- [ ] **서술**: 아브라함이 숨을 몰아쉬며 장막 기둥에 기대섰다. _(근거: 창 18:2~7 달려가 맞음)_
- [ ] **아브라함**: 당신도 거들어 주었구려. 이 늙은이가 오늘은 많이 뛰었소. _(근거: 막간: 인물이 관찰자를 알아본다, 창 18:6~7 급히)_

**선택 1**

- [ ] 「정말 빨리 뛰셨어요!」 → 기쁨
  - [ ] **아브라함**: 아흔아홉 살 다리로는 꽤 빨랐지. / 소 떼까지 가서 송아지를 고르느라 신발도 벗겨졌소. _(근거: 창 17:24 아흔아홉 살, 창 18:7)_
- [ ] 「(물 한 잔을 건넨다)」 → 친절
  - [ ] **서술**: 아브라함이 단숨에 물을 마시고, 남은 물로 이마를 적셨다. _(근거: 창 18:4 물)_
- [ ] 「처음 보는 손님들이죠?」 → 신실
  - [ ] **아브라함**: 처음 보는 얼굴이오. 그래도 나그네는 그냥 보내는 법이 아니오. _(근거: 히 13:2 손님 대접하기를 잊지 말라)_
- [ ] 「제가 상을 지킬게요.」 → 선함 · 친절 새싹 이상에서 열림
  - [ ] **아브라함**: 고맙소. 그럼 나는 손님들 곁에 서 있겠소. / 필요한 것이 있으면 바로 가져오게. _(근거: 창 18:8 곁에 섬)_

- [ ] **아브라함**: 하나님께서 내 이름을 바꾸어 주셨소. 많은 민족의 아버지라는 뜻이오. _(근거: 창 17:5)_
- [ ] **아브라함**: 그런데 사라와 나 사이에는 아직 아들이 없소. _(근거: 창 17:17, 18:11)_

**선택 2**

- [ ] 「그 약속 꼭 이뤄질 거예요.」 → 신실
  - [ ] **아브라함**: 나도 그렇게 믿소. 별을 세던 밤부터 지금까지. _(근거: 창 15:5~6)_
- [ ] 「기다리기 힘드셨겠어요.」 → 인내
  - [ ] **아브라함**: 스물네 해요. 하란을 떠난 날부터 손가락으로 세어 왔소. _(근거: 창 12:4 일흔다섯 살, 창 17:24 아흔아홉 살)_
- [ ] 「사라님도 같은 마음일까요?」 → 사랑
  - [ ] **아브라함**: 그 사람은 웃음으로 버티오. 오늘도 떡 반죽을 하며 웃더군. _(근거: 창 18:6, 18:12 웃음)_

- [ ] **아브라함**: 손님들이 나를 부르시오. 가 봐야겠소. _(근거: 창 18:9로 이어짐)_

## 도감 메모

본문 사실(fact·ref)은 장절과 맞는지, 관찰자 메모(memo)는 본문을 넘어서지 않는지 본다.

- [ ] **마므레 상수리나무** (창 18:1) 여호와께서 아브라함에게 나타나신 곳 — 메모: 한낮에도 나무 그늘 아래는 서늘했다.
- [ ] **세 사람** (창 18:2) 아브라함의 장막 맞은편에 선 세 손님 — 메모: 얼굴은 볼 수 없었지만 그 말씀에 사라가 웃었다.
- [ ] **송아지** (창 18:7) 아브라함이 손님을 위해 고른 좋은 송아지 — 메모: 소 떼에서 가장 부드럽고 좋은 송아지였다.
- [ ] **고운 가루 떡** (창 18:6) 사라가 고운 가루 세 스아로 만든 떡 — 메모: 나무 아래 상에 놓은 떡. 이 스테이지의 기념물이다.
- [ ] **너무 어려운 일** (창 18:14) 여호와에게 너무 어려운 일이 있겠느냐 — 메모: 웃던 사라에게 하신 말씀이다.
