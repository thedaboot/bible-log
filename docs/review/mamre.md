## 막간: 아브라함

사건의 흐름을 바꾸지 않는지, 선택지가 모두 좋은 행동인지, 자라는 열매가 맞는지 본다.

- [ ] **서술**: 아브라함이 숨을 몰아쉬며 장막 기둥에 기대섰다. _(근거: 창 18:2~7 달려가 맞음)_
- [ ] **아브라함**: 당신도 거들어 주었구려. 이 늙은이가 오늘은 많이 뛰었소. _(근거: 막간: 인물이 관찰자를 알아본다, 창 18:6~7 급히)_

**선택 1**

- [ ] 「아흔아홉에 그 속도라니요!」 → 기쁨
  - [ ] **아브라함**: 송아지가 먼저 지쳐서 이긴 것이오. / 신발 한 짝은 소 떼 사이에 두고 왔지만. _(근거: 창 17:24 아흔아홉 살, 창 18:7 소 떼로 달려가 송아지를 고름)_
- [ ] 「(물 한 잔을 건넨다)」 → 친절
  - [ ] **서술**: 아브라함이 단숨에 잔을 비우고 빈 잔을 들여다보았다. _(근거: 창 18:4 물)_
  - [ ] **아브라함**: 손님 발 씻을 물은 넉넉히 떠 놓고, 내 몫은 잊었구려. _(근거: 창 18:4 물을 가져다 발을 씻으시고)_
- [ ] 「처음 보는 손님들이죠?」 → 신실
  - [ ] **아브라함**: 이름도 묻기 전에 상부터 차렸소. / 나그네는 묻지 말고 먼저 먹이는 법이오. _(근거: 창 18:3~5 쉬어 가기를 청함, 히 13:2 손님 대접하기를 잊지 말라)_
- [ ] 「파리는 제가 쫓을게요.」 → 선함 · 친절 새싹 이상에서 열림
  - [ ] **아브라함**: 고맙소. 한낮이라 파리가 손님보다 먼저 상에 앉겠구려. / 나는 손님들 곁에 서 있겠소. _(근거: 창 18:1 한낮 더위, 창 18:8 곁에 섬)_

- [ ] **아브라함**: 하나님께서 내 이름을 바꾸어 주셨소. 많은 민족의 아버지라는 뜻이오. _(근거: 창 17:5)_
- [ ] **아브라함**: 그런데 사라와 나 사이에는 아직 아들이 없소. _(근거: 창 17:17, 18:11)_

**선택 2**

- [ ] 「별처럼 많아질 거예요!」 → 신실
  - [ ] **아브라함**: 그 밤에 세다 만 별이 아직 하늘에 그대로 있소. / 하나도 지워지지 않았으니 약속도 그대로겠지. _(근거: 창 15:5~6 하늘의 별을 셀 수 있나 보라)_
- [ ] 「일흔다섯에 떠나셨다면서요.」 → 인내
  - [ ] **아브라함**: 그러니 스물네 해요. 손가락 발가락을 다 꼽고도 넷이 남소. _(근거: 창 12:4 일흔다섯 살, 창 17:24 아흔아홉 살)_
- [ ] 「사라님도 같은 마음일까요?」 → 사랑
  - [ ] **아브라함**: 사라는 웃음으로 견디는 사람이오. / 실은 나도 그 말씀에 엎드려 웃었소. 사라에겐 비밀이오. _(근거: 창 17:17 아브라함이 엎드려 웃음, 창 18:12 사라의 웃음)_

- [ ] **아브라함**: 손님들이 나를 부르시오. 가 봐야겠소. _(근거: 창 18:9로 이어짐)_

## 도감 메모

본문 사실(fact·ref)은 장절과 맞는지, 관찰자 메모(memo)는 본문을 넘어서지 않는지 본다.

- [ ] **마므레 상수리나무** (창 18:1) 여호와께서 아브라함에게 나타나신 곳 — 메모: 한낮에도 나무 그늘 아래는 서늘했다.
- [ ] **세 사람** (창 18:2) 아브라함의 장막 맞은편에 선 세 손님 — 메모: 얼굴은 볼 수 없었지만 그 말씀에 사라가 웃었다.
- [ ] **송아지** (창 18:7) 아브라함이 손님을 위해 고른 좋은 송아지 — 메모: 소 떼에서 가장 부드럽고 좋은 송아지였다.
- [ ] **고운 가루 떡** (창 18:6) 사라가 고운 가루 세 스아로 만든 떡 — 메모: 나무 아래 상에 차려 낸 떡. 기념으로 한 조각 챙겼다.
- [ ] **너무 어려운 일** (창 18:14) 여호와에게 너무 어려운 일이 있겠느냐 — 메모: 장막 문에서 속으로 웃던 사라에게 하신 말씀이다.
