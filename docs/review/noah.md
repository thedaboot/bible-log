## 막간: 노아

사건의 흐름을 바꾸지 않는지, 선택지가 모두 좋은 행동인지, 자라는 열매가 맞는지 본다.

- [ ] **서술**: 노아가 방주 문턱에 걸터앉아 손바닥의 역청을 긁어냈다. _(근거: 창 6:14 안팎에 역청을 칠함)_
- [ ] **노아**: 당신이 판자를 받쳐 준 덕에 위층까지 막았구려. / 이웃들은 마른 땅에 배를 짓는다고 늘 웃었소. _(근거: 막간: 인물이 관찰자를 알아본다, 창 6:16 삼 층, 벧후 2:5 의를 전하는 노아)_

**선택 1**

- [ ] 「삼백 규빗, 다 재 보셨어요?」 → 인내
  - [ ] **노아**: 규빗이 팔꿈치에서 손끝까지라, 내 팔로 쟀소. / 삼백 번을 재고 나니 팔꿈치가 다 까졌구려. _(근거: 창 6:15 삼백 규빗, 규빗은 팔뚝 길이의 단위)_
- [ ] 「(역청 묻은 손을 닦아 준다)」 → 친절
  - [ ] **서술**: 닦아도 닦아도 손금마다 검은 역청이 배어 나왔다. _(근거: 창 6:14 역청)_
  - [ ] **노아**: 안팎에 칠하라 하셨는데, 내 손까지 칠한 셈이오. _(근거: 창 6:14 안팎에 역청을 칠함)_
- [ ] 「물이 산까지 덮을까요?」 → 신실
  - [ ] **노아**: 나도 본 적 없는 일이오. / 그래도 말씀하신 분을 믿고 판자를 한 장씩 댔소. _(근거: 히 11:7 아직 보이지 않는 일에 경고하심을 받아)_
- [ ] 「내일도 판자 들게요.」 → 선함 · 인내 새싹 이상에서 열림
  - [ ] **노아**: 고맙소. 그런데 내일은 판자 말고 꼴 자루요. / 소 한 쌍이 하루에 먹는 꼴만 해도 산더미라오. _(근거: 창 6:21 먹을 양식을 저축함)_

- [ ] **노아**: 이레가 지나면 비가 온다고 하셨소. _(근거: 창 7:4)_
- [ ] **노아**: 셈과 함과 야벳은 먹이를 나르고, 며느리들은 물을 길어 두었소. _(근거: 창 6:10, 6:21)_

**선택 2**

- [ ] 「여덟 식구 다 함께네요.」 → 화평
  - [ ] **노아**: 나와 아내, 세 아들과 세 며느리, 꼭 여덟이오. / 방이 넉넉하니 잠자리 때문에 다툴 일은 없겠구려. _(근거: 벧전 3:20 여덟 명, 창 7:13, 6:14 방)_

## 도감 메모

본문 사실(fact·ref)은 장절과 맞는지, 관찰자 메모(memo)는 본문을 넘어서지 않는지 본다.

- [ ] **노아** (창 6:8~9) 여호와께 은혜를 입고 하나님과 동행한 사람 — 메모: 굳은살 박인 손으로 마지막 판자까지 받쳤다.
- [ ] **셈** (창 6:10) 노아의 세 아들 가운데 맏아들 — 메모: 먹이 자루를 메고 방주를 몇 번이고 오갔다.
- [ ] **방주** (창 6:14) 고페르 나무로 짓고 안팎에 역청을 칠한 배 — 메모: 지붕 아래 창 하나와 옆으로 낸 문 하나가 있었다.
- [ ] **아라랏 산** (창 8:4) 물이 줄어들 때 방주가 머문 산 — 메모: 물이 걷히자 산비탈에 풀빛이 먼저 돌아왔다.
- [ ] **까마귀** (창 8:7) 노아가 창문을 열고 처음 내보낸 새 — 메모: 물이 마를 때까지 이리저리 날아다녔다.
- [ ] **비둘기** (창 8:11) 노아가 방주 창으로 세 번 내보낸 새 — 메모: 두 번째에는 올리브 잎을 물고 왔고, 세 번째에는 돌아오지 않았다(창 8:12).
- [ ] **도마뱀** (창 7:14) 종류대로 방주에 들어간 땅에 기는 것 — 메모: 배를 땅에 붙이고 꼬리를 흔들며 발판을 올랐다.
- [ ] **물고기** (창 9:2) 하나님께서 사람의 손에 맡기신 바다의 물고기 — 메모: 방주 곁 물 위로 은빛 등이 번쩍 솟았다.
- [ ] **올리브 잎** (창 8:11) 비둘기가 물고 돌아온 새 올리브 잎 — 메모: 물이 걷혔다는 첫 소식이었다. 기념으로 간직했다.
- [ ] **구름 속의 무지개** (창 9:13) 무지개는 하나님과 땅 사이의 언약의 표다 — 메모: 비 갠 하늘에 걸린 무지개를 노아의 가족이 한참 올려다보았다.
