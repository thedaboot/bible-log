## 현재 근거와 검사 범위

- 실측: 이전 UI 검증에서320/390/740/844/768/1280/2560의 해당 화면 배치·구매/소유·키보드·지도 기원 복귀·안전 영역·미리보기20회·멈춤·입력 취소를 확인했다. 전 크기 전 상태의 완주를 뜻하지 않는다.
- 실측: 문구29 정확 대조, 다른 데이터/id/장절/보상/순서 보존, 물동이390 기본·1280 옛 도구4개 상태에서 획득/다시 들기/붓기3/소모와 이어하기n4/n11/n22를 확인했다. 새3D의 물동이 접촉/가림은 다시 봐야 한다.
- 실측: 공용 조명의 정확한 전환 시작값, 낮/저녁/밤 반복2회와 중간 새 요청을 당시 통과했다. 현재 장면별 시간 연결과 마지막 빛 수정 뒤 검사는 남았다.
- 실측: 실제 원근 우물의 [PC 실패](../handoff/assets/well-pc-known-failure.png)·[모바일 캡처](../handoff/assets/well-mobile-last-check.png)와 이관 도구의 [후속PC 단일 통과](../handoff/assets/well-pc-repeat-pass.png)를 모두 보존했다. 카메라 소스 변경 없이 결과가 달라졌고 원인은 미확인이다. 후속JSON에는 카메라/배우 좌표를 기록했다. 현재 검사 통과와 이전 실패 해소를 구분한다.
- 실측(2026-11-14 Claude): PC 실패를 3회 중 1회 재현했다. 관찰자가 카메라 쪽으로 비켜 선 실행(위치 4.32, 3.32)에서만 실패했다. `frameFit`이 초점을 옮길 양을 보는 점의 거리로만 환산해서, 카메라에 가까운 관찰자가 화면에서 더 크게 움직여 위로 지나쳤다. 옮긴 초점에서 다시 재는 반복(최대 4회)으로 고쳤다. `qa-world-art --well-only --aside`(관찰자를 그 자리에 세운다)가 1280×720·390×844에서 통과했고, 네 장면 1280 검사와 check/build도 통과했다. 든 물동이가 종의 몸 일부를 가리는 것은 캡처로 확인했으며 판정 대상이 아니다. 다른 장면의 비켜 선 구도는 장면별 검증에서 본다.
- 실측(2026-11-14 Claude, `qa-f62-64` 1280×720): 하갈 천사는 내려가지 않고 올라 발이 화면 위 밖(ndc 1.38)에 나간 뒤 숨는다. 출산 장면은 해 세기가 낮 1.55에서 1.36으로 기운 때 바뀌고 표본 사이 변화는 0.01 이하다. 엉긴 젖은 소에서 2.6 떨어진 자리에 3초 서도 완료되지 않고, 실제 키로 소 곁(1.6)에 가서 머무르기 게이지를 채워야 완료된다. 젖을 짜는 전용 동작은 없고 종이 곁에 와서 소를 본다.
- 실측(2026-11-14 Claude, `qa-moriah` 1280×720): 순간 이동 없이 실제 키로 첫째·둘째 길목(높이 1.5, 3)에 오르고 나뭇단 받치기를 세 번 해냈다. 목표 고리가 목표 높이에 놓이고(전에는 산 아래 땅에 그려졌다), 대천사는 걷는 표본 215개에서 선 자리의 땅과 높이가 맞았다. 관찰자가 꼭대기까지 따라 올라 제단·제지·숫양 장면의 사람들이 대사 위 화면 안에 있다. 길 안내 화살표는 계단이 아니라 목표를 곧게 가리킨다(미해결, 길찾기 연결이 필요하다). 받치는 손의 접촉 모양은 판정하지 않았다.
- 실측(2026-11-14 Claude, `qa-all-stages` 1280×720, MARKS 캡처): 벧엘·얍복강·요셉·형제들을 실제 키 입력(걷는 거리만 건너뜀)으로 끝까지 마쳤고 오류와 막혀서 순간 이동한 인물 기록이 없다. 캡처로 본 것은 축복 방향(F77), 돌베개(F79), 다리와 건너기(F84), 에서 만남(F85), 창고 엎드림(F95), 고센 도착과 껴안음(F96)이다. 표에 "눈 확인"이 남은 항목은 구현하고 완주만 확인했다.
- 실측(같은 날, 공용): `frameFit`을 두 번 더 고쳤다. 벗어난 사람의 깊이로 환산해 가까운 관찰자에서도 수렴하게 했고, 스테이지가 준 초점은 관찰자가 멀어도 화면에 남게 했다(전에는 관찰자만 크게 잡히고 사건이 화면 밖이었다). 그 뒤 우물 1280·390, 모리아, 다섯 스테이지 완주를 다시 통과했다. 얍복강 이쪽 둑 끝 언덕은 낮췄고, 고센 장막은 떠날 때 보인다.
- 미실행: `qa-first-journey`, `qa-all-stages`의 새 wrapper 완주, 새3D 뒤 전체 입력/저장/모든 스테이지 회귀다. `qa-all-stages`의 순간 이동은 실제 경로 검사로 세지 않는다.
- 미확인: 실제 iOS/PWA·화면 키보드·낭독기·폰FPS·사람이 느끼는 난도/손맛이다. Claude가 도구로 확인한 범위와 사람이 확인해야 할 범위를 분리해서 기록한다.

Claude는 항목을 고칠 때 상태와 실제 파일/명령/크기/결과/미확인을 이 문서에 짧게 갱신한다. 개별 완료는 원본 완료 기준을 실제 제품에서 확인한 뒤 표시하고, 이전 통과를 최신 제품 전체 통과로 바꾸지 않는다.
