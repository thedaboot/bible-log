## 장절 없는 대사

연출 대사(ref: null)다. 본문의 뜻을 넘어서지 않는지 본다.

- [ ] **늙은 종**: 짐 속에 빈 물동이가 하나 있소. 들고 가시오, 쓸 데가 있을 게요. _(근거: 창 24:10 주인의 모든 좋은 것을 가지고 감, 도구 획득(각색))_ `rebekah.jar`
- [ ] **대천사**: 낙타 열 마리가 마실 물이면 물동이로 수십 번이에요. / 금빛 구간에 맞춰 물동이를 기울여 보아요. `rebekah.came`
- [ ] **대천사**: 낙타에게 물을 주던 그 손길로 하나님께서 길을 열어 보이셨어요. / 우물가에서 들은 말씀을 함께 돌아볼까요? `rebekah.go`

## 막간: 리브가

사건의 흐름을 바꾸지 않는지, 선택지가 모두 좋은 행동인지, 자라는 열매가 맞는지 본다.

- [ ] **서술**: 리브가가 젖은 소매를 짜며 우물가 돌에 걸터앉았다. _(근거: 창 24:20 급히 물을 길음)_
- [ ] **리브가**: 같이 길어 줘서 고마워요. 열 마리는 처음이에요. / 물동이를 서른 번은 들었다 놨을 거예요. _(근거: 막간: 인물이 관찰자를 알아본다, 창 24:10, 24:20)_

**선택 1**

- [ ] 「팔 아프지 않아요?」 → 친절
  - [ ] **리브가**: 조금 저려요. 그래도 낙타들이 목을 축이는 소리가 좋더라고요. _(근거: 창 24:19~20)_
- [ ] 「처음 본 나그네인데요.」 → 선함
  - [ ] **리브가**: 목마른 사람에게 물 한 모금 주는 건 이 성의 법이에요. / 낙타는 덤이고요. _(근거: 창 24:18~19)_
- [ ] 「낙타는 끝도 없이 마시네요.」 → 기쁨
  - [ ] **리브가**: 맨 끝 녀석이 제일 많이 마셨어요. 수염까지 다 젖은 거 보세요. _(근거: 창 24:19~20 낙타들이 다 마시기까지)_
- [ ] 「내일은 제가 먼저 길을게요.」 → 신실 · 친절 새싹 이상에서 열림
  - [ ] **리브가**: 좋아요. 그럼 저는 낙타 이름부터 지어 줘야겠네요. _(근거: 창 24:20)_

- [ ] **리브가**: 저 어른은 먼 데서 오셨나 봐요. / 아까부터 아무 말 없이 우리만 보세요. _(근거: 창 24:21 잠잠히 주목함)_
- [ ] **리브가**: 기도하는 사람 얼굴 같았어요. _(근거: 창 24:12~14, 24:26)_

**선택 2**

- [ ] 「좋은 소식을 기다리시나 봐요.」 → 인내
  - [ ] **리브가**: 그럼 오늘 길어 준 물이 좋은 소식이 되면 좋겠어요. _(근거: 창 24:21 길을 평탄하게 하셨는지)_
- [ ] 「함께 가 볼까요?」 → 사랑
  - [ ] **리브가**: 그래요. 오라버니 라반이 손님을 좋아하거든요. _(근거: 창 24:29 라반이 우물로 달려나감)_
- [ ] 「(물 한 바가지를 건넨다)」 → 화평
  - [ ] **서술**: 리브가가 웃으며 받아 마셨다. / 물 긷는 사람이 마지막으로 마시는 물이었다. _(근거: 창 24:20)_

- [ ] **리브가**: 어머, 저 어른이 무언가 꺼내시네요. _(근거: 창 24:22로 이어짐)_

## 도감 메모

본문 사실(fact·ref)은 장절과 맞는지, 관찰자 메모(memo)는 본문을 넘어서지 않는지 본다.

- [ ] **리브가** (창 24:15) 브두엘의 딸, 이삭의 아내 — 메모: 처음 본 나그네의 낙타 열 마리에게 물을 길어 주었다.
- [ ] **라반** (창 24:29) 리브가의 오라버니 — 메모: 누이의 금 코걸이를 보고 우물로 달려 나왔다.
- [ ] **늙은 종** (창 24:2) 아브라함의 모든 소유를 맡은 늙은 종 — 메모: 우물가에서 먼저 기도하고, 응답을 잠잠히 지켜보았다.
- [ ] **낙타** (창 24:10) 종이 끌고 간 주인의 낙타 열 마리 — 메모: 한 마리가 한 번에 물동이 여러 개를 비웠다.
- [ ] **나홀의 성** (창 24:10) 아브라함의 동생 나홀의 집안이 사는 성 — 메모: 저녁이면 여인들이 성 밖 우물로 물을 길으러 나왔다.
- [ ] **금 코걸이** (창 24:22) 종이 리브가에게 준 반 세겔 금 코걸이 — 메모: 응답을 받은 날의 기억. 이 스테이지의 기념물이다.
- [ ] **인도하시는 하나님** (창 24:27) 여호와께서 길에서 나를 인도하셨다 — 메모: 종이 우물가에서 머리를 숙여 드린 찬송이다.
