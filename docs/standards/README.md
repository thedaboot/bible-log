# 바이블로그 표준

작업하면서 정한 규칙과 기준을 주제별로 모은다. 새 기준이 생기면 해당 문서에 추가하고, 맞는 문서가 없으면 새로 만든 뒤 이 목록에 한 줄 더한다.

| 문서 | 다루는 것 |
|---|---|
| [dialogue.md](dialogue.md) | 대사 데이터, 장절, 하나님 이름표와 높임, 말투, 줄바꿈 |
| [ui.md](ui.md) | 화면 토큰, 글꼴, 대사 창, 퀘스트 창, HUD, 메뉴(상태 창·도감), 꾸미기, 퀴즈, 정렬과 가독성 |
| [growth.md](growth.md) | 성장 수치와 속도, 보상, 열매, 레벨·칭호, 관계, 도감 데이터, 닮은 인물, 저장 |
| [art-3d.md](art-3d.md) | 3D 색표와 공용 부품, 인물·동물·옷·소품, 충돌, 길 안내 |
| [quests-and-staging.md](quests-and-staging.md) | 퀘스트 설계, 장면 연출, 카메라 |
| [workflow.md](workflow.md) | 문서 관리, 점검 방법, 브라우저 확인 방법 |

- 게임의 결정(무엇을 만들지)은 [`../design.md`](../design.md)에 둔다. 이 폴더는 어떻게 만들지에 대한 규칙만 둔다.
- 세션 인수인계는 [`../handoff/`](../handoff/)에 따로 둔다.
- 각 규칙 옆의 `[적용됨]`은 코드에 반영된 규칙이고, `[미적용]`은 정했지만 아직 코드에 반영하지 않은 규칙이다.
