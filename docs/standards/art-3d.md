# 3D 표준

## 공용 부품

새 3D 요소는 `src/props.js`의 색표(`PAL`)와 공용 부품을 먼저 쓴다. 없으면 공용 부품을 추가한 뒤 쓴다. 장면마다 비슷한 물체를 따로 만들지 않는다. [적용됨]

| 부품 | 쓰는 곳 |
|---|---|
| `makeCloud` | 천국 가장자리, 창조의 하늘, 꾸미기 방 |
| `makeLightPillar` | 천국의 음성, 아담 지음, 가죽옷 |
| `makeSpiritLight` | 창 1:2 하나님의 영, 창 3:8 거니시는 하나님 |
| `makeFigure`, `dressFigure` | 관찰자, 아담, 하와 |
| `makeAngel` | 대천사, 그룹(케루빔) |
| `makeTree`, `makeAnimal`, `makeBird`, `makeSerpent` | 창조, 에덴 |
| `makeFruit`, `makeBasket` | 에덴 열매 퀘스트 |
| `makeBridge`, `makeThornBush` | 에덴의 강 다리, 동산 밖 거친 땅 |
| `makeWaypoint` | 모든 길 안내 |
| `makeDressingRoom` | 지상 꾸미기 화면 |

- 지금 모양은 모두 임시 도형이다. 직접 만든 .glb 모델이 나오면 같은 함수 안에서 모델을 불러오도록 바꾼다.

## 하나님과 관찰자

- 하나님은 형상 없이 빛기둥, 움직이는 빛, 음성으로만 표현한다. [적용됨]
- 관찰자: 천국에서는 반투명하게 빛나는 형체, 지상에서는 사람 모습에 은은한 빛과 발밑 빛 고리를 둔다. [적용됨]

## 사실감

- 동물은 그 동물로 바로 알아볼 수 있어야 한다. 상자를 이어 붙인 공용 몸통에 동물마다 실루엣 특징을 반드시 더한다. [적용됨]
  - `makeAnimal(color, size, kind)`의 `kind`로 고른다. 픽셀화 후처리에서 작은 부품은 뭉개지므로, 특징 부품은 몸통과 색을 다르게 하고 크게 만든다(예: 사자 갈기는 짙은 색 둥근 덩어리, 코끼리 귀는 옆으로 펼친 짙은 판).
  - 사슴: 가는 다리, 짧은 꼬리, 가지 친 뿔
  - 사자: 갈기, 꼬리 끝 술
  - 코끼리: 큰 귀, 긴 코, 굵은 다리
  - 양: 둥근 털 덩어리 몸, 작은 머리
  - 말: 긴 목, 갈기, 긴 꼬리
  - 곰: 둥근 귀, 묵직한 몸
- 옷은 이름에 맞는 모양이어야 한다. 망토는 목에서 여며 어깨부터 늘어지고, 아래로 갈수록 넓어지는 천으로 만든다. [적용됨]
  - 원뿔대의 뒤쪽 절반(양면 재질) + 목둘레 깃 + 금빛 여밈. 나그네 옷도 같은 망토를 쓴다.
- 소품은 성경에 나오는 물건으로 한다. 현대 소품과 섞지 않는다. [적용됨]
  - 지금 소품: 지팡이, 물매, 양각 나팔, 기름 뿔병, 물동이, 목자 가방, 두건, 등잔, 두루마리. 칸에 들어가도록 이름은 5글자 이하로 쓴다.
  - 소품은 꾸미기 화면이 아니라 인벤토리에서 손에 든다. 도구와 꾸미기의 구분은 [growth.md](growth.md) "손에 드는 물건과 인벤토리"를 따른다. 새 소품을 만들면 `src/data/items.js`와 픽셀 아이콘(`src/icons.js`)도 함께 더한다. [적용됨]
  - 소품을 빼면 예전 저장값은 '없음'으로 옮겨진다(`cleanEarth`, `npm run check`가 점검).
  - 후보: 지팡이(출 4:2), 물매(삼상 17:40), 양각 나팔(수 6:4), 기름 뿔병(삼상 16:13), 두루마리(렘 36:2), 등잔(마 25:1), 물동이(창 24:15), 목자의 가방(삼상 17:40)
  - 머리띠, 목도리처럼 성경 근거가 약한 소품은 뺀다.

## 움직임

- 동물은 실제 동물처럼 움직인다. 다리는 엉덩이에 축을 둔 그룹으로 만들어 대각선 짝으로 흔들고, 걸을 때 몸이 살짝 오르내린다. 멈추면 몸을 숙여 풀을 뜯는다(`animateAnimal`). 큰 동물일수록 걸음이 느리다. [적용됨]
- 동물은 걷다 서다를 번갈아 한다. 방향은 천천히 틀고(초당 2.2라디안 이하), 많이 돌아야 하면 속도를 줄인다. 서로 겹치지 않게 살짝 밀어낸다. [적용됨]
- 동물은 자기 터가 있는 강 이쪽에서만 돌아다닌다. 강 건너로 가야 할 때(아담에게 모이기, 터로 돌아가기)는 다리 어귀를 지나 걸어서 간다. 막히면 먼저 옆으로 비켜 돌아가고, 8초 넘게 못 가면 그때만 목표 자리에 둔다. [적용됨]
- 아담·하와는 천천히 걸어도 관찰자만큼 흔들리며 걷는다(`animateFigure`의 `ref` 1.3). 멈춰 있을 때는 숨 쉬며 무게를 좌우로 옮기고, 바라볼 곳으로 천천히 돌아선다. 대사가 나오면 말하는 인물이 고개를 끄덕이며 들썩인다. [적용됨]
- 아담이 관찰자를 따라다닐 때도 강 건너면 다리로 따라온다. [적용됨]
- `npm run check`가 모이기·돌아가기와 따라오기에서 순간 이동이 없는지 점검한다.

## 충돌과 지형

- 나무, 바위, 물 같은 장애물은 플레이어, 인물, 동물이 통과하지 못한다. 장애물마다 원형 충돌 반지름을 둔다. [적용됨]
  - 에덴은 `collide(p, r)` 하나로 막는다(나무·바위·샘·문기둥은 원, 강은 폭 0.8의 선분). 관찰자 반지름 0.35, 인물 0.3, 동물은 크기의 0.45배.
  - 연출에서 인물이나 동물이 장애물에 막혀 1.5초 넘게 다가가지 못하면 목표 자리에 둔다. 연출이 멈추는 것보다 낫다.
  - 나무 배치는 고정된 난수로 만든다. `npm run check`가 출발점에서 걸어서 모든 목표(강 끝, 열매 나무, 동물, 선악나무)에 닿는지 격자로 탐색해 점검한다.
- 강은 물 위로 걸을 수 없게 하고, 건널 곳에 나무 판자 다리나 징검다리를 둔다. 다리 위치는 퀘스트 동선에 맞춘다. [적용됨]
  - 네 강이 동산을 네 구역으로 나누므로 강마다 다리를 하나씩 둔다. 연출 지점(아담, 하와, 숨는 나무, 동쪽 문)은 모두 출발점과 같은 구역에 둔다.
  - 연출에서 인물이 서는 자리와 다리 어귀에는 나무를 심지 않는다(`keep` 목록).
- 연출에서 인물이 서는 자리와 카메라 사이(+x, +z 쪽 너비 2.8, 길이 7의 띠)에는 나무를 두지 않는다(`inFrontOfScene`, `npm run check`가 점검). [적용됨]

## 길 안내

- 목표 위에는 금빛 표식, 발밑에는 목표 쪽을 가리키는 화살표를 둔다. 모든 장면이 같은 방식을 쓴다. [적용됨]
- 화살표는 물이나 지형 위에서도 또렷해야 한다. 바닥에서 조금 띄우고, 깊이 검사를 끄거나 그리는 순서를 뒤로 미뤄 다른 물체에 묻히지 않게 한다. [적용됨]

## 픽셀화 후처리 주의

- 투명도 0으로 숨긴 물체도 윤곽선이 그려진다. 숨길 때는 `visible = false`를 쓴다. [적용됨]
