# 대사 표준

## 데이터

- 대사는 `src/data/`에 둔다(`prologue.js`, `creation.js`, `eden.js`). 코드를 몰라도 본문과 한 줄씩 대조할 수 있어야 한다. [적용됨]
- 한 줄은 `{ who, text, ref }`다. `ref`는 장절(`'창 2:7'`, `'창 2:10~14'`)이고, 본문에 근거가 없는 연출 대사는 `ref: null`로 두어 각색임을 드러낸다. [적용됨]
- 본문은 쉬운 말로 각색한다. 개역개정 원문은 싣지 않는다(저작권). [적용됨]
- `{name}`은 플레이어 이름, `{nameVoc}`은 '이름+아/야'로 바뀐다. [적용됨]
- `npm run check`가 화자, 장절 형식, 줄바꿈, 이름표 규칙을 점검한다. 규칙을 바꾸면 `scripts/check-data.mjs`도 함께 바꾼다.

## 화자와 이름표

| who | 이름표 | 쓰는 곳 |
|---|---|---|
| `narr` | (없음) | 서술 |
| `elohim` | 엘로힘 | 창 1:1~2:3의 하나님 |
| `voice` | YHWH | 프롤로그, 창 2:4부터의 하나님 |
| `angel` | 대천사 | 동행하는 천사 |
| `adam`, `eve`, `serpent` | 아담, 하와, 뱀 | 등장인물 |

- 하나님의 이름표는 본문에 쓰인 이름을 따른다. 창 2:4 이후 대사에 `elohim`을 쓰면 점검에서 실패한다. [적용됨]

## 높임과 말투

- 하나님을 주어로 쓸 때는 '하나님께서', '여호와 하나님께서'로 쓰고 서술어도 높인다. 예: "하나님께서 빛을 보시고 좋다고 하셨다." 서술, 대천사, 인물 대사 모두 같다. [미적용]
  - 하나님 자신의 대사(YHWH, 엘로힘)는 본문처럼 하나님의 말로 둔다. 높임 대상이 아니다.
- 대천사의 권유는 줄임말 대신 본딧말로 쓴다. 예: "함께 봐요" → "함께 보아요", "가 봐요" → "가 보아요". [미적용]
- 대천사는 사건 장면 한가운데 끼어들어 감정을 해설하지 않는다. 장면을 소개하거나 정리할 때만 말한다. [미적용]

## 줄바꿈 (2판)

화면에서 읽기 좋게 줄을 나누는 기준이다. 한 줄 기준은 36자다(이름은 3글자로 센다).

1. 두 문장 이상이고 합쳐서 36자를 넘으면, 반드시 문장과 문장 사이에서 줄을 바꾼다.
   - 예: "여자의 후손이 뱀의 머리를 상하게 한다는 말씀, 꼭 기억해 두세요.\n나중에 다시 만나게 될 약속이에요."
2. 한 문장이 36자를 넘으면 의미 단위(쉼표나 연결어미 뒤)에서 한 번 바꾼다. 두 줄 길이가 비슷해야 하고, 짧은 꼬리(12자 미만)만 다음 줄로 넘어가면 안 된다.
   - 예: "여호와 하나님께서 땅과 하늘을 만드시던 날,\n들에는 아직 풀 한 포기 없었고 땅을 일굴 사람도 없었다."
   - 예: "이제 사람이 손을 뻗어 생명나무 열매까지 따 먹고\n영원히 살게 해서는 안 된다."
3. 36자 이하는 한 줄로 둔다. 쉼표가 있어도 바꾸지 않는다.
   - 예: "하늘에 빛들이 있어 낮과 밤을 나누고, 계절과 날과 해를 이루어라."
4. 화면이 좁으면 대사 창이 알아서 줄을 바꾼다. 남는 꼬리를 줄이려고 대사 본문에 `text-wrap: balance`를 쓴다. [미적용]
5. 화면 안내 문구(꾸미기 설명 등)도 같은 기준을 따른다. 예: "땅에서도 사람들 눈에는 보이지 않아요.\n여러 시대를 함께 걸을 모습을 골라 주세요." [미적용]

- 상태: 1판(30자, 문장 사이에서만 허용)이 점검 스크립트에 들어가 있다. 2판으로 바꾸고 모든 대사에 다시 적용해야 한다. [미적용]
