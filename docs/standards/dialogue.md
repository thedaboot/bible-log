# 대사 표준

## 데이터

- 대사는 `src/data/`에 둔다(`prologue.js`, `creation.js`, `eden.js`, `cain.js`). 코드를 몰라도 본문과 한 줄씩 대조할 수 있어야 한다. [적용됨]
- 한 줄은 `{ who, text, ref }`다. `ref`는 장절(`'창 2:7'`, `'창 2:10~14'`)이고, 본문에 근거가 없는 연출 대사는 `ref: null`로 두어 각색임을 드러낸다. [적용됨]
- 본문은 쉬운 말로 각색한다. 개역개정 원문은 싣지 않는다(저작권). [적용됨]
- `{name}`은 플레이어 이름, `{nameVoc}`은 '이름+아/야'로 바뀐다. [적용됨]
- `npm run check`가 화자, 장절 형식, 줄바꿈, 이름표 규칙을 점검한다. 규칙을 바꾸면 `scripts/check-data.mjs`도 함께 바꾼다.
- 도감의 관찰자 메모(`src/data/codex.js`의 `memo`)와 닮은 인물 문장(`LIKENESS.text`)은 본문에 없는 각색이다. 감수 목록(`npm run review`, 1d에서 만든다)에 올린다. 닮은 인물 문장은 긍정형으로 쓰고, 대사가 아니므로 줄바꿈 기호 없이 쓴다([growth.md](growth.md) "닮은 인물"). [적용됨: 점검만]

## 막간과 각색 목록

- 막간은 `{ who, steps }`로 쓴다. `steps`는 `{ say: [대사] }`와 `{ choose: [선택지] }`가 번갈아 오고, choose는 바로 앞 say의 마지막 대사에서 뜬다. 선택지는 `{ text, fruit, need?, reply }`다(`src/data/eden.js` `INTERLUDE`). [적용됨]
- 막간과 짧은 인사의 대사는 모두 각색이라 `ref: null`이고, 근거 장절이나 이유를 `basis`에 적는다(`npm run check`가 점검). [적용됨]
- 인물의 말투는 본문 시대에 맞춰 예스럽게 쓴다(아담: "~소", "~구려"). 관찰자의 말(선택지)은 오늘의 존댓말이다. [적용됨]
- 막간 대사는 앞뒤 본문의 시간 표현과 어긋나지 않게 쓴다. 예: 아벨이 "내일은 일찍 나서야 하오"라고 한 바로 뒤라서 창 4:3의 "세월이 지난 후"를 "때가 되어"로 옮겼다(2026-11-01). [적용됨]
- 선택지의 답(reply)은 그 선택에 구체적으로 답한다. 숫자, 이름, 몸짓처럼 그 자리에서만 나올 말을 넣는다. 예: 「한 마리도 안 빠졌어요!」 → "어미 다섯에 어린양 하나, 다 있소." [적용됨]
- 선택지를 쓰는 결은 아래 "막간 선택지 쓰는 법"을 따른다.
- 선택지 글은 18자 이하 한 줄이다(`npm run check`). 대사처럼 줄바꿈 2판을 지키는 대상은 답(reply)이다. [적용됨]
- `npm run review`가 스테이지마다 `docs/review/<스테이지>.md`를 만든다. 장절 없는 대사, 막간(선택지·자라는 열매·여는 조건 포함), 짧은 인사, 도감 메모, 닮은 인물 문장을 체크리스트로 뽑는다. 이 파일은 손으로 고치지 않고 데이터를 고친 뒤 다시 뽑는다. [적용됨]

## 막간 선택지 쓰는 법 (2026-11-02, 창세기에서 정한 결)

사용자가 "이 느낌으로 이후 성경도 가자"고 정한 기준이다. 출애굽기부터 요한계시록까지 막간·깊은 대화의 선택지와 답은 이 결로 쓴다. [적용됨: 창세기 막간]

### 원칙

1. **그 장면에서만 나올 말을 쓴다.** 칭찬·맞장구·덕담("참 좋았어요", "든든해 보여요")은 어느 장면에나 붙어서 읽히지 않는다. 인물이 방금 한 말, 화면에 보이는 것, 본문의 숫자·이름·물건에 기댄다.
2. **세 선택지의 결을 나눈다.** 공감 하나, 질문 하나, 몸짓이나 가벼운 농담 하나. 셋이 모두 칭찬이거나 모두 질문이면 고를 맛이 없다. 괄호 속 몸짓("(말없이 곁에 앉는다)")은 화면에서 맨 아래에 놓인다.
3. **관찰자는 오늘의 사람이다.** 선택지는 플레이어(관찰자)가 오늘의 존댓말로 하는 말이다. 친구처럼 묻고 놀라되, 인물을 가르치거나 결말을 미리 말하지 않는다(그 인물은 아직 뒷이야기를 모른다).
4. **답은 첫마디에서 바로 받는다.** 질문이면 대답부터("코끼리였소.", "암염소만 이백이오."), 농담이면 웃음이나 맞받아침부터("들켰네요.", "어머, 그러네요."). 그다음 한 줄에 인물의 마음을 붙인다. 답에는 숫자, 이름, 몸짓처럼 그 자리에서만 나올 말을 넣는다.
5. **재치의 경계.** 농담은 사람과 사물(짐승 이름, 짐 싸기, 발이 아픈 것)을 향한다. 하나님, 제사, 죄와 고통, 죽음은 농담 대상으로 삼지 않는다. 슬픔이나 결단의 장면(모리아로 가는 길, 형들 앞의 요셉)과 깊은 대화에는 농담을 넣지 않고 담백한 질문·공감으로 쓴다.
6. **복선은 가볍게.** 본문의 다음 장면을 살짝 건드려도 좋다("짝 이름도 미리 지어 둘까요?" → 창 2:23). 결말을 말해 버리지는 않는다.
7. **근거를 단다.** 답의 사실(곡식 종류, 짐승 수)이 본문에 없으면 basis에 "(각색)"을 적는다.

### 전과 후 (창세기에서 실제로 바꾼 것)

| 장면 | 전 | 후 |
|---|---|---|
| 에덴 아담 | 이름마다 꼭 어울렸어요! | 곰은 누가 봐도 곰이네요. |
| 에덴 아담 | 오래 바라보고 지어 주셨죠. | 제일 오래 걸린 건 누구예요? |
| 1-3 아벨 | 아끼던 녀석인데 괜찮아요? | 어린양한테는 말했어요? |
| 1-3 아벨 | 형님이랑 같이 가서 좋겠어요. | 형님 밭엔 뭐가 났어요? |
| 1-6 사래 | 사래님도 먼 길 오셨잖아요. | 발은 사래님이 더 아프죠? |
| 1-6 사래 | 두렵지 않으셨어요? | 갈 곳도 모르고 떠나셨죠? |
| 1-12 요셉 | 관원장이 곧 기억할 거예요. | 관원장, 술잔 드느라 잊었나 봐요. |

답의 예:
- 「제일 오래 걸린 건 누구예요?」 → 아담: "코끼리였소. 코가 그리 긴 짐승은 처음이라 한참 마주 서 있었소."
- 「어린양한테는 말했어요?」 → 아벨: "아직이오. 오늘 밤엔 풀을 한 줌 더 주었소. / 아깝지 않다면 거짓말이지."
- 「발은 사래님이 더 아프죠?」 → 사래: "들켰네요. 신발 끈 자리가 다 까졌어요. / 그래도 장막 접는 일은 이제 눈 감고도 해요."

### 쓰기 전에 볼 것

- 이 선택지를 다른 스테이지에 옮겨 붙여도 말이 되면 다시 쓴다.
- 셋 중 둘이 같은 결(칭찬·질문)이면 하나를 바꾼다.
- 답 첫마디가 "그렇소", "맞아요"로만 시작해 선택지를 되풀이하면 대답이나 맞받아침으로 바꾼다.
- 18자 이하 한 줄(`npm run check`), 답은 줄바꿈 2판, 열매(fruit)·여는 조건(need)·개수·순서는 저장 기록이 기대므로 다듬을 때 바꾸지 않는다.

## 대사 다듬기 (2026-11-02, 창세기 전체를 다듬으며 정한 결)

- 말씀을 각색할 때 본문에 있는 숫자·물건·몸짓(은 이십 세겔, 어깨에 멘 물 부대, 목을 끌어안음)은 남기고, 예스러운 한자어(범사, 소산, 인자, 결박)는 뜻이 같은 쉬운 말로 바꾼다. 예: "당신이 나에게 축복하지 않으면 가게 하지 않겠습니다." → "저를 축복해 주시기 전에는 놓지 않겠습니다."(창 32:26) [적용됨: 창세기]
- 인물의 말은 그 사람의 처지가 묻어나게 쓴다. 예: "여호와께서 정말 여기 계셨는데, 나는 그것도 모르고 잤구나."(창 28:16) [적용됨: 창세기]
- 대천사의 말도 그 자리의 구체적인 사실로 쓴다. 예: "도저히 다 셀 수가 없어요." → "백까지 세었는데, 그 사이에 별이 또 돋았어요." 스테이지를 마무리하는 말("오늘 들은 말씀을 함께 돌아볼까요?")은 장소나 물건을 넣어 바꾼다("돌베개 곁에서 들은 말씀을"). [적용됨: 창세기]
- 인물이 다른 인물에게 하나님을 말할 때도 '하나님께서'로 높인다. 선택지도 같다. [적용됨]
- 화면 문구(퀘스트 목표, 도전 칸 이름)와 대사가 같은 것을 가리키면 같은 말을 쓴다(1-12 꿈의 이삭·암소). [적용됨]

## 높임과 말투

- 하나님을 주어로 쓸 때는 '하나님께서', '여호와 하나님께서'로 쓰고 서술어도 높인다. 예: "하나님께서 빛을 보시고 좋다고 하셨다." 서술, 대천사, 인물 대사 모두 같다. [적용됨]
  - 하나님 자신의 대사(YHWH, 엘로힘)는 본문처럼 하나님의 말로 둔다. 높임 대상이 아니다.
  - 예외: 뱀의 대사는 높이지 않는다("하나님이 정말 … 하셨느냐?", 창 3:1). 하나님을 깎아내리는 간교한 말투가 본문의 뜻이다. [적용됨]
- 대천사의 권유는 줄임말 대신 본딧말로 쓴다. 예: "함께 봐요" → "함께 보아요", "가 봐요" → "가 보아요". [적용됨]
  - 권유형 '-아요'에만 적용한다. 요청형 '-아 주세요'("잘 지켜봐 주세요")는 그대로 둔다.
- 대천사는 사건 장면 한가운데 끼어들어 감정을 해설하지 않는다. 장면을 소개하거나 정리할 때만 말한다. [적용됨]

## 줄바꿈 (2판)

화면에서 읽기 좋게 줄을 나누는 기준이다. 한 줄 기준은 36자다. 띄어쓰기는 세고, 문장부호(. , ? ! …)는 세지 않으며, 이름은 3글자로 센다. 아래 예시가 모두 이 셈법으로 36자 이하다. [적용됨]

1. 두 문장 이상이고 합쳐서 36자를 넘으면, 반드시 문장과 문장 사이에서 줄을 바꾼다. [적용됨]
   - 예: "여자의 후손이 뱀의 머리를 상하게 한다는 말씀, 꼭 기억해 두세요.\n나중에 다시 만나게 될 약속이에요."
2. 한 문장이 36자를 넘으면 의미 단위(쉼표나 연결어미 뒤)에서 한 번 바꾼다. 두 줄 길이가 비슷해야 하고, 짧은 꼬리(12자 미만)만 다음 줄로 넘어가면 안 된다. [적용됨]
   - 한 번 갈라도 두 줄을 넘는 긴 구절(창 3:15 등)은 같은 장절의 대사 두 개로 나눈다. 본문의 절이 갈리면 장절도 나눠 단다(창 3:17, 창 3:19).
   - 예: "여호와 하나님께서 땅과 하늘을 만드시던 날,\n들에는 아직 풀 한 포기 없었고 땅을 일굴 사람도 없었다."
   - 예: "이제 사람이 손을 뻗어 생명나무 열매까지 따 먹고\n영원히 살게 해서는 안 된다."
3. 대사 하나는 두 줄까지다(대사 창 높이). 세 줄이 되면 대사를 둘로 나눈다(`npm run check`). [적용됨]
4. 36자 이하는 한 줄로 둔다. 쉼표가 있어도 바꾸지 않는다. [적용됨]
   - 예: "하늘에 빛들이 있어 낮과 밤을 나누고, 계절과 날과 해를 이루어라."
5. 화면이 좁으면 대사 창이 글자 폭을 재서 줄과 쪽을 나눈다(일반 두 줄, 하나님 말씀 세 줄이 한 쪽). 데이터는 이 2판 기준으로 쓰고, 휴대폰 쪽 나누기는 [ui.md](ui.md) "대사 창"이 맡는다. [적용됨]
6. 화면 안내 문구(꾸미기 설명 등)도 같은 기준을 따른다. 예: "땅에서도 사람들 눈에는 보이지 않아요.\n여러 시대를 함께 걸을 모습을 골라 주세요." [적용됨]
   - 안내 문구는 `white-space: pre-line`인 요소(`.modal__text`)에 넣어야 `
`이 줄바꿈으로 보인다.

- 상태: 2판이 `scripts/check-data.mjs`의 `wrapErrors`에 들어가 있고, 모든 대사가 통과한다. 안내 문구(코드 안의 문자열)는 점검 대상이 아니라서 직접 맞춘다. [적용됨]
