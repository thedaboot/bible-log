# 화면(UI) 표준

## 토큰과 글꼴

- 색, 글꼴, 간격, 움직임은 `src/tokens.css`의 토큰만 쓴다. CSS에 색 값을 직접 적지 않는다(꾸미기 색 견본처럼 데이터에서 오는 색만 예외). [적용됨]
- 큰 제목("바이블로그", "첫째 날")만 픽셀 글꼴 Galmuri11(12px의 배수 크기)을 쓰고, 나머지 글자는 모두 프리텐다드를 쓴다. [적용됨]
- 모든 한국어 문장에 `word-break: keep-all`을 둔다. 제목과 짧은 안내에는 `text-wrap: balance`를 둔다. [적용됨: 일부]
- 움직임은 `transform`과 `opacity`만 쓰고, `prefers-reduced-motion`에서는 효과를 끈다. [적용됨]

## 가독성과 정렬

- 버튼, 칩, 메뉴 글자는 두 줄로 꺾이지 않는다(`white-space: nowrap`). [적용됨]
- 칩이나 버튼 묶음은 같은 너비의 격자(`grid-template-columns: repeat(auto-fill, minmax(…, 1fr))`)로 놓는다. 줄이 바뀌어도 열이 맞아야 한다. 지금처럼 글자 길이만큼의 칩이 들쭉날쭉 이어지면 안 된다. [적용됨]
  - 꾸미기 칩은 `minmax(7rem, 1fr)`이다. 가장 긴 이름(5글자, "나그네 옷")이 한 줄에 들어가는 너비다. 이름이 더 길어지면 이 값을 함께 늘린다.
- 무언가를 얻거나 맞혔을 때 결과를 글자만 툭 띄우지 않는다. 짧은 강조 효과(색 번쩍임, 체크 표시가 그려지는 움직임, 살짝 커졌다 돌아오기)를 함께 준다. [적용됨]
  - 획득 알림은 `toast(text, { gain: true })`로 띄운다. 퀘스트 창에서 방금 끝낸 목표는 칸이 커졌다 돌아오고 줄이 금빛으로 한 번 번쩍인다(`is-new`).
- 모든 화면은 320, 375, 768px 폭에서 가로 스크롤 없이 보여야 한다. [적용됨]

## 대사 창

- 픽셀 테두리 패널. 이름표는 본문 첫 글자와 같은 세로선에 맞추고, 본문은 두 줄 높이 안에서 세로 가운데에 놓는다. [적용됨]
- 하나님의 말씀(YHWH, 엘로힘)은 밝은 바탕, 금빛 테두리, 가운데 정렬, 한 단계 크고 굵은 글자로 쓴다. [적용됨]
- 본문 위 여백(테두리 안쪽에서 글자까지)과 아래 여백(글자에서 장절 구분선, 장절이 없으면 아래 줄까지)을 같게 둔다. 둘 다 `--pad`에서 정한다(위 `--pad - 5px`, 구분선 위 `--pad - 10px`, 줄 높이 여유를 셈한 값). 모든 화자, 한 줄·두 줄, 320~1200px에서 위아래 차이가 1px 이하다. [적용됨]
- 장절은 책갈피 표시와 함께 구분선 아래에 둔다. 장절이 없으면 구분선도 숨긴다. [적용됨]
- 글자는 한 자씩 나오되, 아직 안 나온 글자도 자리를 차지해서 줄바꿈 위치가 처음부터 고정된다. [적용됨]
- 줄바꿈 기준은 [dialogue.md](dialogue.md)를 따른다.
- 지나간 대사를 놓쳤을 때 돌아볼 수 있게, 같은 섹션(`say` 한 번) 안에서는 이전 대사로 돌아간다. 대사 창 아래 '이전' 버튼(첫 대사에서는 숨김), ←·Backspace 키를 쓴다. 되돌린 대사는 타자 효과 없이 바로 보이고, 연출(`onLine`)도 그 대사에 맞춘다. 섹션을 넘어가면 돌아가지 않는다(지나간 연출을 되돌리지 않기 위해). [적용됨]

## 퀘스트 창과 조작 안내

- 퀘스트 창은 오른쪽 위(휴대폰은 위쪽), 조작 안내는 따로 아래쪽에 둔다. 대사가 나오는 동안 조작 안내는 숨긴다. [적용됨]
- 목표 문구는 해야 할 행동을 동사로 쓴다. 예: "비손 강으로 이동하기", "사자에게 다가가 이름 듣기", "무화과 따서 바구니에 담기". "열매 1 모으기" 같은 번호 문구는 쓰지 않는다. [적용됨]
- 조작 안내는 PC에서 키캡, 휴대폰에서 탭·밀기 모양을 보여 준다. [적용됨]

## 꾸미기 창

- 천국 꾸미기는 옆에 붙는 작은 창, 지상 꾸미기는 전용 화면(오른쪽 전체 높이 패널, 휴대폰은 아래 시트)으로 띄운다. [적용됨]
- 항목이 많으면 탭으로 나눈다. 항목 사이 간격은 넓게 둔다. [적용됨]
- 고를 때 캐릭터는 그 항목다운 방식으로 바뀐다(`dressFx`, main.js). 크기 깜빡임만으로 끝내지 않는다. [적용됨]
  - 옷 모양: 발밑부터 새 옷이 차오른다(경계에 빛 고리, 재질 clippingPlanes).
  - 피부·옷 색·머리색·천국 빛깔: 새 색이 위에서 아래로 물든다(경계 고리는 새 색).
  - 머리 모양·수염: 머리에 빛 알갱이가 모였다가, 모인 순간 새 모양으로 바뀌고 흩어진다.
  - 소품: 빛 한 덩이가 손으로 날아와 알갱이로 터지며 소품이 된다.
  - 키: 0.45초 동안 부드럽게 늘고 준다. 나를 감싸는 빛: 발밑 고리가 새 색으로 퍼진다.
  - 무작위: 발밑부터 새 모습이 차오른 뒤 머리·손·발밑에 빛이 차례로 지나간다.
  - 연달아 빨리 고르면 진행 중인 차오름을 바로 끝내고 새 효과를 시작한다. 효과가 끝나면 효과용 물체와 자르기 설정은 모두 지운다.
- 첫 화면에서 다른 장면(꾸미기 방 등)으로 갈 때는 첫 화면을 띄운 채로 빛으로 다 덮은 뒤에 첫 화면을 치운다. 순서가 바뀌면 덮이는 동안 뒤의 천국 장면이 드러난다. [적용됨]
- 천국 꾸미기를 마친 사용자는 첫 화면의 '커스텀 변경하기'에서 '천국 모습 변경하기'와(지상 모습을 고른 적이 있으면) '지상 모습 변경하기'로 다시 고를 수 있다. 같은 꾸미기 창을 쓰고, 저장한 뒤 첫 화면으로 돌아온다. [적용됨]
  - 장면을 옮길 때는 먼저 화면을 빛으로 덮고, 새 장면의 모습(예: 지상 모습)을 입힌 뒤에 걷어 낸다. 덮기 전에 장면을 바꾸거나 모습을 입히기 전에 걷으면 이전 모습이 비친다. [적용됨]
- 탭을 바꾸면 밑줄 막대 하나가 옆으로 미끄러져 옮겨 가고(`.look__tabline`), 새 항목은 탭 방향에서 짧게 들어온다(220ms, transform·opacity). [적용됨]
- 칩·견본·무작위 버튼을 누르면 짧게 눌렸다 튀어 오른다(`.is-picked`). 3D 캐릭터는 바뀐 부위 높이(머리·옷·소품 등)에서 금빛 고리가 퍼지고 살짝 커졌다 돌아온다. 무작위는 고리가 발밑에서 머리까지 훑고 올라간다(main.js `dressFx`). 움직임 줄이기 설정에서는 3D 효과를 끈다. [적용됨]
- 칩은 같은 너비의 격자로 정렬한다(위 '가독성과 정렬' 참고). [적용됨]

- 아이콘이 붙은 버튼은 아이콘을 글자 기호(◀, ▶) 대신 CSS 도형(`clip-path`)으로 그리고 `inline-flex` + `align-items: center`로 글자와 세로 중심을 맞춘다. 글자 기호는 글꼴마다 기준선이 달라 처져 보인다. [적용됨]

## 게이지와 도감 카드

- 머무르기 게이지는 화면 아래 가운데의 픽셀 패널이고, 채움은 `transform: scaleX`로만 바꾼다. [적용됨]
- 도감 카드는 획득 효과(커졌다 돌아오기, 금빛 번쩍임)와 함께 펼쳐지고, 누르거나 Space·Enter를 누르거나 2.8초가 지나면 닫힌다. [적용됨]

## 퀴즈 창

- 문제와 선택지가 한눈에 읽히도록 창을 넓게(최소 32rem) 쓰고, 문제 글자를 크게 둔다. 문제의 어미가 혼자 다음 줄로 떨어지면 안 된다(예: "지으셨나 / 요?"). [적용됨]
  - 창 너비 34rem, 문제는 `text-wrap: balance`와 `word-break: keep-all`로 나눈다.
- 정답을 고르면 강조 효과와 함께 장절을 보여 준다. 틀리면 짧게 흔들리는 효과와 함께 다시 고르게 한다. [적용됨]
  - 정답: 칸이 살짝 커졌다 돌아오고 오른쪽에 체크 표시가 나타난다. 오답: 좌우로 흔들리고 줄이 그어진다.
